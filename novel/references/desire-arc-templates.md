# 角色欲望弧线模板库（升级详细版 v1.5）

本文件提供多种热门成人小说题材的**完整欲望弧线模板**。每个模板包含四个阶段、关键转折点、对应情欲节奏建议、推荐Kink组合及写作要点，方便直接套用或修改。

**通用设计原则**：
- 欲望弧线必须与主线剧情紧密结合
- 每阶段都要有清晰的**心理变化**和**关系进展**
- 情欲强度随弧线逐步提升（低 → 中 → 高 → 极高）
- 每场重要H戏必须推动弧线前进

### 通用欲望弧线检查清单
1. 每个阶段是否有清晰的心理变化？
2. 情欲强度是否随阶段逐步升级？
3. 重要H戏是否推动了弧线前进？
4. 最终结局是否与初始欲望形成呼应或反转？
5. 是否存在足够的情感张力与冲突？
