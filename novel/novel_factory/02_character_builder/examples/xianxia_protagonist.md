# 姓名

陆沉

# 核心性格

冷静、偏执、极强控制欲。

# 背景

寒门子弟，父母被宗门迫害致死。

# 核心欲望

摆脱底层命运，登临绝顶。

# 最大弱点

不信任任何人，包括盟友。

# 对话风格

短句、低情绪、不解释。

例：
"嗯。"
"说重点。"
"不需要。"

# 人物弧光

从冷血求生者成长为帝国建立者。

初期：活下去
中期：掌控命运
后期：建立秩序
终局：孤独的王

# 成长路线

炼气期（1-100章）：苟活求存
筑基期（100-300章）：小势力崛起
金丹期（300-600章）：宗门争斗
元婴期（600-900章）：帝国争霸
化神以上（900章+）：终极秘密

# 情绪系统

愤怒触发：被背叛、被轻视
表达方式：沉默，冷暴力
执念：我不需要任何人

# 人格锁定

永不信任任何人。
永不解释自己。
永不主动帮助人。
只有在确认利益时才合作。
面对威胁优先自保。
