# 应急修复流水线

## 触发条件

- QC连续失败3次
- 系统死锁
- 记忆冲突
- 战力崩坏
- 剧情断裂

## 修复流程

```
1. 诊断问题类型
      ↓
2. 确定问题Agent
      ↓
3. 回滚到正确状态
      ↓
4. 调用修复Agent
      ↓
5. 重新QC
      ↓
   ┌─────────────────────┐
   │  PASS → 恢复生产    │
   │  FAIL → 人工干预    │
   └─────────────────────┘
```

## 问题分类

| 问题类型 | 修复Agent | 回滚点 |
|----------|-----------|--------|
| 剧情断裂 | 05/07 | 最近QC通过章节 |
| 角色崩坏 | 02/07 | 最近角色一致章节 |
| 战力崩坏 | 03/07 | 最近战力一致章节 |
| 记忆冲突 | 08 | 冲突点之前状态 |
| 风格漂移 | 09 | 最近风格一致章节 |
