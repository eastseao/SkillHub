# 章节生成流水线

## 单章生成流程（7步）

```
1. 07_chapter_engine
      ↓
2. 08_memory_manager（同步状态）
      ↓
3. 09_style_system（风格应用）
      ↓
4. 11_quality_control（质量检测）
      ↓
   ┌─────────────────────┐
   │  PASS → 5. 下一阶段  │
   │  FAIL → 回滚 07     │
   └─────────────────────┘
      ↓
5. 10_platform_adapter（多平台适配）
      ↓
6. 输出到各平台目录
      ↓
7. loop_control（下章推进）
```

## 输入

- 当前章节编号
- 当前Arc信息
- 内存管理器状态
- 风格配置

## 输出

- 各平台章节文件
- 更新后的内存状态
- QC报告

## 时间控制

- 单章目标时间：≤5分钟
- 超出时间触发告警
