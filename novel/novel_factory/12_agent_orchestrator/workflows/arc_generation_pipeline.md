# Arc生成流水线

## Arc级生成流程

```
Phase 1: Arc结构设计
  05_master_plot（确认Arc目标）
  06_arc_designer（设计Arc结构）
       ↓
Phase 2: 批量章节生成
  [循环 07 → 08 → 09 → 11]
  直到Arc内所有章节完成
       ↓
Phase 3: Arc级QC
  整体一致性检测
  伏笔完成度检测
  爽点分布检测
       ↓
   ┌─────────────────────┐
   │  PASS → 下一Arc     │
   │  FAIL → 整体修订    │
   └─────────────────────┘
```

## Arc内批量章节

- 每个Arc含 10-30 章
- 每章独立QC
- Arc结束做整体检测
- Arc间有衔接检测
