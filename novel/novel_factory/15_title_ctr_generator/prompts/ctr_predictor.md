# CTR点击率预测模型

## 评分维度

### 1. 冲突强度（0-30）

| 分值 | 标准 |
|------|------|
| 25-30 | 强烈对抗/压制/生死冲突 |
| 20-24 | 明显权力/身份冲突 |
| 15-19 | 一般冲突 |
| 0-14 | 平淡/无冲突 |

### 2. 情绪刺激（0-25）

| 分值 | 标准 |
|------|------|
| 20-25 | 愤怒/打脸/逆袭/碾压 |
| 15-19 | 惊讶/反转/恐惧 |
| 10-14 | 一般情绪词 |
| 0-9 | 无情绪词汇 |

### 3. 信息缺口（0-25）

| 分值 | 标准 |
|------|------|
| 20-25 | 结果完全未知，制造强烈好奇 |
| 15-19 | 部分信息已知，结果未知 |
| 10-14 | 有悬念但不够强 |
| 0-9 | 结果已揭示/无悬念 |

### 4. 新奇程度（0-20）

| 分值 | 标准 |
|------|------|
| 16-20 | 完全非套路，反转强烈 |
| 12-15 | 部分非套路 |
| 8-11 | 轻微套路 |
| 0-7 | 严重套路化 |

---

# CTR公式

```
CTR_SCORE =
  0.30 * conflict +
  0.25 * emotion +
  0.25 * curiosity_gap +
  0.20 * novelty
```

---

# CTR评级

| CTR分数 | 评级 | 推荐行动 |
|---------|------|----------|
| 90-100 | S级 | 强烈推荐 |
| 80-89 | A级 | 推荐 |
| 70-79 | B级 | 可用 |
| 60-69 | C级 | 建议优化 |
| <60 | D级 | 不推荐 |

---

# 输出格式

```
标题：《XXX》

各维度得分：
- 冲突强度：XX/30

- 新奇程度：XX/20

综合评级：X级
推荐行动：强烈推荐/推荐/可用/建议优化/不推荐
```
