# 钩子强度分析器

## 评分维度

### 1. 第1秒钩子（0-40）

用户看到标题的第1秒判断。

| 分值 | 标准 |
|------|------|
| 35-40 | 第1秒就有强烈冲击/冲突/危险 |
| 25-34 | 第1秒有明确情绪词/冲突 |
| 15-24 | 第1秒有一定吸引力 |
| 0-14 | 第1秒平淡无奇 |

### 2. 利益关系（0-30）

标题中是否明确利益/生死/权力关系。

| 分值 | 标准 |
|------|------|
| 25-30 | 生死/权力/身份压制/资源争夺 |
| 20-24 | 明显利益冲突 |
| 10-19 | 一般利益关系 |
| 0-9 | 无利益关系 |

### 3. 悬念制造（0-30）

是否制造了"必须知道结果"的欲望。

| 分值 | 标准 |
|------|------|
| 25-30 | 完全未知，结果极度好奇 |
| 20-24 | 部分未知，好奇心强 |
| 10-19 | 有悬念但不够强 |
| 0-9 | 结果已揭示 |

---

# 钩子评分公式

```
HOOK_SCORE =
  0.40 * first_second +
  0.30 * benefit_relation +
  0.30 * suspense
```

---

# 钩子评分标准

| 评分 | 钩子强度 | 推荐影响 |
|------|----------|----------|
| 85-100 | 极强 | 算法强力推荐 |
| 70-84 | 强 | 正常推荐 |
| 55-69 | 中等 | 勉强推荐 |
| 40-54 | 弱 | 降低曝光 |
| <40 | 极弱 | 停止推荐 |
