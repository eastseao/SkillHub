# 推荐算法匹配器

## 番茄算法核心逻辑

番茄推荐算法判断点击率的逻辑：

```
点击 = 标题冲突 + 情绪刺激 + 不确定性
```

---

## 高CTR标题结构

### ✅ 加分项

| 要素 | 番茄推荐权重 |
|------|--------------|
| 数字冲突 | 高 |
| 权力冲突 | 高 |
| 身份反转 | 高 |
| 极端结果未揭示 | 高 |
| 情绪词（废物/大帝/碾压） | 中高 |

### ❌ 扣分项

| 要素 | 番茄推荐权重 |
|------|--------------|
| 平铺直叙 | 高负 |
| 无冲突 | 高负 |
| 结果已揭示 | 中负 |
| 无情绪词 | 中负 |

---

## 番茄算法适配评分

| 分值 | 算法适配度 |
|------|------------|
| 90-100 | 完全适配，推荐爆款 |
| 75-89 | 适配，推荐 |
| 60-74 | 基本适配，可用 |
| <60 | 不适配，建议重写 |

---

## 番茄爆款标题特征

### 1️⃣ 必须有

- [x] 冲突（对抗/压制）
- [x] 情绪刺激
- [x] 不确定性/悬念

### 2️⃣ 最好有

- [x] 数字（具体化）
- [x] 身份反差（废物/大帝）
- [x] 时间差（三年/一天）

### 3️⃣ 不能有

- [ ] 总结性语言
- [ ] 结果已揭示
- [ ] 无情绪词汇

---

```
算法适配分析

标题：《XXX》

加分项：
- [x] [加分项1]
- [x] [加分项2]

扣分项：
- [ ] [扣分项1]

算法适配评分：XX/100

适配度评级：完全适配/适配/基本适配/不适配

- [具体建议]
```
