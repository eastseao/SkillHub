# 世界名称

九荒界

# 世界等级

高武修仙世界

# 世界核心规则

灵气决定一切，修为境界为修炼核心。

境界划分：炼气、筑基、金丹、元婴、化神、合道、大乘、渡劫、飞升。

# 超凡力量来源

灵气潮汐，每千年大潮，灵气暴涨，伴随大机缘。

# 世界核心矛盾

飞升资源正在枯竭，各势力争夺最后的机会。

# 文明结构

五大域：东荒、南疆、西极、北原、中天。

各域文明形态不同：东荒修仙、南疆蛊虫、西极炼体、北原巫术、中天百家。

# 世界危险区域

禁地：北原深渊、南疆万毒林、西极死亡沙海、东荒归墟、中天禁区。

# 世界隐藏真相

所谓仙界其实是收割场，飞升者皆成燃料。

# 世界终极秘密

上古仙战真相：所有飞升者都被收割，世界只是圈养之地。

# 适合的故事类型

废柴逆袭流、丹药流、符箓流、灵宠流、门派流
