# 世界名称

大周天朝

# 世界等级

低武古代王朝

# 世界核心规则

儒家秩序，天子天命，文武分途。

# 超凡力量来源

无超凡力量，纯武道武功。

境界：后天、先天、大师、宗师、大宗师、通天。

# 世界核心矛盾

藩王割据、外族入侵、朝廷党争。

# 文明结构

中原王朝、草原帝国、海上岛国、西域诸国。

各区域文化差异显著，存在文明冲突。

# 世界危险区域

北疆雪原、西域荒漠、南疆瘴地、东海绝境。

# 世界隐藏真相

开国皇帝并非凡人之身，皇室血脉藏着远古秘密。

# 世界终极秘密

天下大势分久必合，冥冥中有天数操控。

# 适合的故事类型

权谋流、江湖流、战争流、历史穿越流、科举流
