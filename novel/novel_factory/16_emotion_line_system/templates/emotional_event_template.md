## 情绪事件示例

```markdown
# 情绪事件：师门背叛

## 事件基本信息
- 事件类型：背叛
- 发生章节：第80章
- 涉及人物：主角、师父、宗门
- 重要性：核心事件

## 情绪触发分析

### 触发源
师父当着宗门所有人的面宣布：主角被逐出师门。

### 触发情绪
- 愤怒：100（最高）
- 绝望：80
- 压抑：90

### 情绪积累
- 之前：师父一直很信任主角（信任度90）
- 积累：没有任何预兆（突然背叛更痛）
- 触发阈值：0（直接崩塌）

## 情绪驱动

### 情绪→决策
愤怒+绝望→决定隐姓埋名，暗中修炼

### 决策→行动
离开宗门，寻找新的力量

### 行动→新剧情
→ 新师父出现
→ 修炼新功法
→ 伏笔：查明背叛真相

## 读者反应预期
- 极度愤怒（替主角不平）
- 心疼主角
- 期待复仇
- 想知道为什么师父会背叛

## 情绪强度评估

| 维度 | 评分 |
|------|------|
| 情绪冲击 | 95 |
| 冲突强度 | 90 |
| 爽感释放 | 80（延迟） |
| 代入程度 | 95 |
| **综合评分** | 90 |
```
