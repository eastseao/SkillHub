# 16_emotion_line_system 情感线体系

## 定位

> ❤️ **"爽点可以靠设计，但让读者持续追更的核心，是情感线。"**

这是一个"贯穿1000+章节的隐性主线系统"：

- 剧情决定"发生什么"
- 情感线决定"读者为什么一直看下去"

---

## 核心使命

管理小说中的情感发展：

- 主角情感成长曲线
- 人物关系情感网络
- 情绪驱动剧情设计

## 核心评分公式

```
EMOTION_SCORE =
  0.30 × 情绪波动强度
+ 0.30 × 情绪冲突强度
+ 0.20 × 情绪释放强度
+ 0.20 × 情绪代入感
```

---

## 主角情绪三阶段

### 阶段1：底层情绪（弱势期）

- 恐惧、压抑、不甘、自卑
- 情绪分值：0-40
- 读者感受：憋屈、共情、想看反转

### 阶段2：反抗情绪（成长期）

- 愤怒、反击、逆袭快感
- 情绪分值：40-70
- 读者感受：爽、期待、复仇欲望满足

### 阶段3：掌控情绪（巅峰期）

- 冷静、统治感、无情决策
- 情绪分值：70-100
- 读者感受：快感持续、权力幻想满足

---

## 情绪跌宕核心节奏

```
压 → 爆 → 放 → 再压
```

禁止：

- 持续压抑超过50章无爆发
- 持续爽感超过20章无压抑
- 情绪平稳无波动

---

## 关系类型与情绪特征

| 关系 | 情绪波动 | 信任变化 | 冲突频率 |
|------|----------|----------|----------|
| 亲情 | 稳定 | 慢升/慢降 | 低 |
| 师徒 | 渐变 | 稳定上升 | 中 |
| 爱情 | 剧烈波动 | 快速变化 | 高 |
| 敌对 | 强冲突 | 持续降低 | 极高 |
| 利益 | 变化大 | 随利益波动 | 中高 |

---

## 背叛情绪模型（六阶段）

```
信任建立 → 情感依附 → 背叛预兆 → 背叛发生 → 情绪崩塌 → 复仇驱动
```

背叛是网文最强大的情绪催化剂之一。

---

## 依附度分级

| 分级 | 读者反应 | 写作重点 |
|------|----------|----------|
| 路人 | 无所谓 | 增加人物弧线 |
| 好感 | 会关注 | 增加戏份 |
| 心疼 | 追着看 | 增加苦难+反转 |
| 死忠 | 不许角色死 | 保护角色+给好结局 |

---

## 设计原则

1. **没有情绪 = 没有小说**
2. **情绪必须驱动剧情**（不是装饰，是动力）
3. **每章必须有情绪变化**（否则直接判水文）
4. **情绪必须可量化**（必须能评分/优化/预测）
