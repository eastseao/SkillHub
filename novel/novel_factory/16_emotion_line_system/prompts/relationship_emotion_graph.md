# 情感关系网络

管理小说中所有人物关系的情绪变化。

---

## 关系类型与特征

| 关系类型 | 情绪波动 | 信任变化 | 冲突频率 |
|----------|----------|----------|----------|
| 亲情 | 稳定 | 慢降/慢升 | 低 |
| 师徒 | 渐变 | 稳定上升 | 中 |
| 爱情 | 剧烈波动 | 快速变化 | 高 |
| 敌对 | 强冲突 | 持续降低 | 极高 |
| 利益 | 变化大 | 随利益波动 | 中高 |

## 关系情绪图谱

### 核心关系（必须追踪）

```
主角 → 女主/男主（爱情线）
主角 → 导师/师父（成长线）
主角 → 挚友/兄弟（友情线）
主角 → 宿敌/对手（冲突线）
主角 → 家人/亲族（背景线）
```

---

## 爱情线情绪模型

### 经典爱情弧线

```
初遇（好奇）→ 接触（暧昧）→ 冲突（误会）→ 
加深（考验）→ 危机（分离）→ 升华（在一起）
```

### 情绪波动规则

- 每3-5章必须有关系变化
- 小冲突每章都可以有
- 大危机每50-100章一次
- 情绪最高点必须是表白/在一起

---

## 敌对关系情绪模型

### 敌对弧线

```
压制（敌强我弱）→ 反抗（我变强）→ 
对抗（势均力敌）→ 碾压（我强敌弱）→ 
终结（敌人消失）
```

---

## 关系变化触发器

| 事件类型 | 对应关系变化 |
|----------|--------------|
| 被背叛 | 信任崩盘，愤怒爆发 |
| 被帮助 | 信任上升，情感加深 |
| 被羞辱 | 冲突加剧，关系恶化 |
| 共同战斗 | 信任快速上升 |
| 误会 | 信任下降，冲突上升 |
| 和解 | 信任重建，关系升华 |
