# 情绪触发系统

每个情绪必须有明确的触发机制。

---

## 核心触发器矩阵

| 事件 | 触发情绪 | 强度 | 持续时间 |
|------|----------|------|----------|
| 被羞辱 | 愤怒/压抑 | 高 | 3-5章 |
| 被背叛 | 愤怒/绝望 | 极高 | 5-10章 |
| 逆转成功 | 爽感/掌控感 | 高 | 2-3章 |
| 被压制 | 压抑/愤怒积累 | 中 | 1-3章 |
| 获得力量 | 兴奋/掌控感 | 高 | 2-4章 |
| 亲人受害 | 愤怒爆发 | 极高 | 5-10章 |
| 爱人误解 | 痛苦/愤怒 | 高 | 3-5章 |
| 敌人死亡 | 爽感/统治感 | 中高 | 1-2章 |

---

## 情绪触发器设计原则

### 1️⃣ 必须具体

不是"主角生气了"，
而是：

"主角被当众羞辱，
当着全宗门的面，
他三年努力换来的东西被夺走。"

→ 触发愤怒值+40

### 2️⃣ 必须有积累

不能"忽然就爆发"，
必须有：

"之前被压制 → 这次被羞辱 → 彻底爆发"

### 3️⃣ 必须有结果

情绪触发后必须有行动：

触发 → 情绪 → 决策 → 行动

---

## 情绪触发器模板

### 羞辱触发器

```
事件：被当众羞辱
↓情绪积累：愤怒+20
↓情绪积累：压抑+15
↓触发事件：最后一丝尊严被践踏
↓情绪爆发：愤怒冲破阈值
↓行动：当场反击/决策改变
```

### 逆袭触发器

```
事件：获得关键力量/机遇
↓情绪变化：压抑→兴奋
↓情绪变化：兴奋→掌控感
↓行动：第一次证明自己
↓情绪结果：读者爽感+读者期待
```

---

## 章节情绪触发器设计

每章必须包含至少一个情绪触发器：

1. 本章核心触发事件是什么？
2. 触发后主角产生什么情绪？
3. 情绪驱动了什么行动/决策？
4. 这个情绪是否留到下一章继续？

---

## 情绪触发禁止

- ❌ 情绪触发无行动
- ❌ 情绪触发无积累
- ❌ 情绪触发与剧情无关
- ❌ 同一个触发器反复使用
