# 情绪与剧情同步器

规则：每个剧情节点必须有情绪变化，每个情绪变化必须推动剧情。

---

## 同步核心公式

```
剧情事件 → 情绪变化 → 角色决策 → 新的剧情
```

---

## 同步原则

### 1️⃣ 剧情驱动情绪

每个剧情事件必须产生情绪变化：

| 剧情事件 | 情绪变化 |
|----------|----------|
| 被羞辱 | 愤怒+30 |
| 获得力量 | 兴奋+掌控感 |
| 亲人被害 | 愤怒+绝望 |
| 敌人求饶 | 爽感+统治感 |

---

### 2️⃣ 情绪推动决策

情绪变化必须影响角色决策：

| 情绪状态 | 可能决策 |
|----------|----------|
| 愤怒爆发 | 立即反击 |
| 极度压抑 | 自我怀疑/爆发 |
| 兴奋+掌控感 | 挑战更强的敌人 |
| 绝望 | 寻找新出路/绝地反击 |

---

### 3️⃣ 决策推动剧情

角色决策必须产生新的剧情：

| 决策 | 新剧情 |
|------|--------|
| 决定反击 | 新的冲突 |
| 决定隐忍 | 压抑积蓄 |
| 决定复仇 | 追踪敌人 |
| 决定保护 | 新人物出场 |

---

## 同步检测

写完章节后检查：

```
剧情节点 → 情绪变化 → 决策 → 新剧情
    ✓           ✓        ✓        ✓
```

如果任何一个环节断了，就需要修改。

---

## 同步模板

### 正确同步示例

```
剧情：主角被当众羞辱（第50章）

情绪变化：
- 愤怒+40
- 压抑+30
- 不甘+20

决策：决定隐忍+暗中积蓄力量

新剧情：
- 主角开始秘密修炼
- 发现羞辱他的人有秘密
- 暗线伏笔埋下
```

### 错误同步示例

```
剧情：主角被当众羞辱

情绪变化：无（主角很淡定）

决策：无（主角什么都没做）

新剧情：无（直接跳到下一件事）
```

---

## 情绪-剧情对照表

| 情绪阶段 | 对应剧情 | 典型章数 |
|----------|----------|----------|
| 底层压抑 | 被压制/被欺负 | 1-100章 |
| 反抗萌芽 | 小反抗/小胜利 | 100-150章 |
| 爆发逆袭 | 大胜利/复仇 | 150-200章 |
| 新的压制 | 更强敌人出现 | 200-250章 |
| 更大逆袭 | 终极决战 | 250-300章 |
| 新秩序 | 统治建立 | 300+章 |

---

## 禁止规则

- ❌ 有剧情无情绪变化
- ❌ 有情绪变化无角色决策
- ❌ 有决策无新剧情
- ❌ 情绪和剧情不匹配（如：大好事发生→主角很悲伤）
