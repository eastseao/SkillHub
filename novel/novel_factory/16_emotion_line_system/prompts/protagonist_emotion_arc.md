# 主角情绪成长曲线

定义主角从"底层情绪"到"统治级心态"的完整成长弧线。

---

## 三阶段情绪模型

### 阶段1：底层情绪（弱势期）

特征：

- 恐惧（被压制/被欺负）
- 压抑（无法释放）
- 不甘（想反抗但无力）
- 自卑（被羞辱/被看不起）

情绪分值：

- 恐惧：60-80
- 压抑：70-90
- 不甘：50-70
- 自卑：40-60

读者感受：

- 憋屈
- 共情
- 想看到反转

---

### 阶段2：反抗情绪（成长期）

特征：

- 愤怒（爆发积累的压抑）
- 反击（开始还手）
- 逆袭（小的胜利）
- 野心（想要更多）

情绪分值：

- 愤怒：60-80
- 反击：50-70
- 逆袭快感：40-60
- 野心：30-50

读者感受：

- 爽
- 期待
- 复仇欲望满足

---

### 阶段3：掌控情绪（巅峰期）

特征：

- 冷静（决策无情）
- 统治感（权力碾压）
- 无情（不被情感左右）
- 孤寂（站在顶端）

情绪分值：

- 冷静：70-90
- 统治感：60-80
- 无情：50-70
- 孤寂感：30-50

读者感受：

- 快感持续
- 权力幻想满足
- 史诗感

---

## 情绪弧线模板

```
第1-100章：底层情绪积累
第100-300章：反抗情绪爆发
第300-500章：掌控情绪建立
第500-1000章：巅峰与孤寂
```

---

## 情绪起伏节奏

每个大阶段内部必须有小的情绪起伏：

```
底层期：压抑 → 小反抗 → 被压制 → 更强压抑
成长期：逆袭 → 被打击 → 更大逆袭
巅峰期：统治 → 威胁 → 更强统治
```

---

## 情绪弧线检测

写完章节后检测：

- [ ] 主角当前处于哪个情绪阶段？
- [ ] 本章情绪相比上章是上升还是下降？
- [ ] 情绪变化是否符合弧线规律？
- [ ] 是否为下一阶段的情绪转变做了铺垫？
