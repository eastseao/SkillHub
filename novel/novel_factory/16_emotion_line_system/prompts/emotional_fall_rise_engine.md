# 情绪跌宕系统

必须遵循：压 → 爆 → 释放 → 再压

---

## 核心节奏模型

```
压抑（积累）→ 拉扯（小反抗）→ 爆发（大爽点）→ 短暂释放 → 新的压抑
```

---

## 情绪节奏类型

### 短周期（单章）

```
前500字：压抑积累
中1000字：拉扯
后500字：爆发+留钩
```

### 中周期（10-30章）

```
第1-10章：压抑积累
第11-15章：小爽点
第16-20章：更大压抑
第21-25章：大爽点
第26-30章：释放+新伏笔
```

### 长周期（100+章）

```
第1-100章：底层情绪+压抑
第100-150章：第一次大爆发（逆袭）
第150-200章：新的威胁+更大的压抑
第200-250章：更大的逆袭
第250-300章：统治感建立
```

---

## 情绪跌宕规则

### 禁止出现

- ❌ 持续压抑超过50章无爆发
- ❌ 持续爽感超过20章无压抑
- ❌ 情绪平稳无波动
- ❌ 单边上涨或单边下跌

### 必须出现

- ✅ 压抑后必须有释放
- ✅ 爽点后必须有新的威胁
- ✅ 情绪低谷后必须有反弹
- ✅ 每个情绪峰值后必须有回落

## 各阶段情绪节奏

### 底层期（1-100章）

节奏：压 → 小反抗 → 更强压制

```
1-30章：强烈压抑（憋屈）
31-40章：小反抗（爽一下）
41-60章：更强的压制（更憋屈）
61-70章：更大的反抗（更爽）
...
```

### 成长期（100-500章）

节奏：逆袭 → 被打击 → 更大逆袭

```
100-120章：大逆袭（爽）
121-140章：新的强大敌人（压）
141-180章：艰难成长（积蓄）
181-200章：再次逆袭（更爽）
...
```

### 巅峰期（500+章）

节奏：统治 → 威胁 → 绝对统治

```
500-520章：统治感建立（快感）
521-550章：最高威胁出现（紧张）
551-600章：终极决战（爆发）
601+章：新秩序建立（余韵）
```

---

## 情绪跌宕检测

章节写完后检查：

- [ ] 本章情绪是在压还是在放？
- [ ] 如果是压，压了多少章了？快到爆发点了吗？
- [ ] 如果是放，放完后是否有新威胁铺垫？
- [ ] 情绪波动幅度够不够大？
