# 修仙小说主线示例

# 主线目标

主角寻找天道真相，打破命运束缚

# 核心冲突

修士追求长生 vs 天道规则束缚

# 世界阶段

凡界（1-100章）→ 灵界（100-300章）→ 仙界（300-600章）→ 神界（600-1000章）

# Arc结构

## Arc1：废物崛起（1-50章）

目标：改变废物身份
冲突：被羞辱/退婚
高潮：觉醒，打脸所有人
钩子：发现父亲失踪真相

## Arc2：宗门成长（50-150章）

目标：成为宗门天才
冲突：宗门内斗/外敌入侵
高潮：宗门大比夺冠
钩子：发现宗门背后秘密

## Arc3：帝国风云（150-300章）

目标：建立势力
冲突：帝国战争
高潮：成为帝国驸马
钩子：仙界降临

## Arc4：仙界争锋（300-600章）

目标：成为仙界强者
冲突：仙界势力战争
高潮：打败仙界巨头
钩子：发现天道真相

## Arc5：终极对决（600-1000章）

目标：改变天道
冲突：终极战争
高潮：打破命运
结局：成为新的天道

# 核心伏笔

- 父亲失踪真相（Arc1埋，Arc3回收）
- 天道背后秘密（全程伏笔，Arc5揭示）
- 主角真实身世（Arc2埋，Arc4揭示）

# 核心谜题

- 天道为何存在？
- 主角与天道什么关系？
- 仙界之上还有什么？
