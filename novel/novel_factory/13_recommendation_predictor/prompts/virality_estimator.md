# 病毒传播潜力评估器

## 爆款小说的传播路径

```
单个读者 → 转发朋友圈/群 → 10个新用户 → 继续转发 → 爆发
```

## 传播触发点检测

### 高传播触发点（高概率转发）

| 触发点 | 转发动机 | 分值 |
|--------|----------|------|
| 极致打脸 | "我必须让朋友看看" | 25 |
| 逆天反转 | "这结局太离谱了" | 25 |
| 极致碾压 | "太爽了必须分享" | 20 |
| 金句 | "这句话太绝了" | 15 |
| 悬念断点 | "你们觉得接下来会怎样" | 15 |

### 中传播触发点

| 触发点 | 转发动机 | 分值 |
|--------|----------|------|
| 爽点 | 还不错 | 10 |
| 情绪共鸣 | 感同身受 | 10 |

### 低传播触发点

| 触发点 | 转发动机 | 分值 |
|--------|----------|------|
| 平铺直叙 | 无 | 0 |
| 压抑无释放 | 太难受了 | -10 |

## VIRAL_SCORE计算

```
VIRAL_SCORE =
  (触发点类型分 × 触发点数量) +
  (情绪峰值分) +
  (金句分)
上限100
```

## 传播阶段预测

| VIRAL_SCORE | 传播阶段 | 预估爆发时间 |
|-------------|----------|--------------|
| 90-100 | 全网爆发 | 3-7天 |
| 80-89 | 朋友圈爆款 | 7-14天 |
| 70-79 | 社群传播 | 14-21天 |
| 60-69 | 缓慢传播 | 21-30天 |
| <60 | 无传播 | 无法爆发 |
