# 情绪爆点检测器

## 爆款小说的核心

番茄小说的爆款公式：

```
爆款 = 持续情绪波动 + 周期性爽点释放
```

## 爆点类型与分值

| 爆点类型 | 分值 | 说明 |
|----------|------|------|
| 打脸 | 25 | 当众羞辱对手，读者获得优越感 |
| 逆袭 | 25 | 弱者打败强者，绝对反转 |
| 权力碾压 | 20 | 主角用绝对实力压制 |
| 资源获取 | 15 | 获得宝物/功法/财富/权力 |
| 情绪释放 | 15 | 压抑后的情绪爆发 |

## 爆点密度评估

| 每X字一个爆点 | RAGE_SCORE | 推荐影响 |
|---------------|------------|----------|
| 每1000字 | 90-100 | 爆款潜力 |
| 每2000字 | 75-89 | 良好 |
| 每3000字 | 60-74 | 一般 |
| 每5000字+ | <60 | 平淡 |

## 情绪峰值检测

### 有效情绪峰值

- 主角被贬低 → 情绪压抑（-10）
- 主角反击 → 情绪释放（+50）
- 结果公布 → 读者爽感（+30）

### 无效情绪

- 纯悲伤描写（无后续爽点）
- 纯愤怒描写（无释放出口）
- 内心独白过多（节奏拖慢）

## RAGE_SCORE计算

```
RAGE_SCORE =
  (爆点类型分 × 爆点数量) +
  (密度分) +
  (情绪峰值分)
上限100分
```

