# 09_style_system 风格控制器

## 定位

> 🎨 **"统一整本小说气质的风格控制中枢（工业级写作操作系统）"**

如果说：

- `07 chapter_engine` = 写"这一章"
- `08 memory_manager` = 让整本书"不崩设定"
- 那么
- `09 style_system` = 决定"这本书读起来像谁写的"

## 核心使命

统一整本小说的**语言气质、叙事手感、爽点表达方式**，确保1000+章节风格不漂移、气质不崩坏。

## 调用顺序

```
05_master_plot
↓
06_arc_designer
↓
07_chapter_engine
↓
09_style_system（嵌入式调用，每章都要引用）
```

## 四大核心原则

| 原则 | 说明 |
|------|------|
| **风格必须"全局一致"** | 否则读者会感觉换作者 |
| **风格必须"可执行"** | 不是文学描述，是规则系统 |
| **风格必须"服务爽点"** | 不是艺术风格，是工业风格 |
| **风格必须"可检测"** | 否则无法长期控制 |

## 高级扩展系统

### 1、风格锁定系统

> 一旦确定风格，全书不可变

### 2、角色语气差异系统

> 不同角色必须不同语言习惯

### 3、爽点表达控制器

> 控制"爽感表达方式统一"

### 4、风格加速系统

> 后期节奏更快、语言更紧

## 风格分期规则

| 阶段 | 节奏 | 描写 | 情绪 | 语言 |
|------|------|------|------|------|
| 初期（1-100章） | 较慢 | 详细 | 逐步建立 | 标准 |
| 中期（100-500章） | 加快 | 精简 | 稳定高潮 | 紧凑 |
| 后期（500+章） | 极快 | 极简 | 持续爆发 | 简洁有力 |

## 题材风格映射

| 题材 | 风格类型 | 叙事 | 对话 | 节奏 |
|------|----------|------|------|------|
| 修仙/玄幻 | 古典简洁 | 第三人称 | 简短有力 | 快节奏 |
| 都市/现代 | 直接代入 | 第三人称 | 口语化 | 较快 |
| 黑暗/压抑 | 冷静克制 | 客观叙述 | 短句沉默 | 慢热爆发 |
| 搞笑/系统 | 轻松有趣 | 灵活 | 幽默吐槽 | 跳跃 |
| 战争/权谋 | 严肃张力 | 宏大视角 | 暗藏机锋 | 紧凑压迫 |

## 一致性检查机制

每章必须检查：

- [ ] 叙事语气是否统一？
- [ ] 对话是否区分角色？
- [ ] 动作描写是否风格一致？
- [ ] 情绪表达是否符合基调？
- [ ] 节奏是否符合阶段要求？
- [ ] 是否触犯禁用规则？
