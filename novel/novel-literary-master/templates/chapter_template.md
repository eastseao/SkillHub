# 标准章节模板

## 章节结构

### 一、开头（10%）

必须包含：
- 钩子
- 情绪切入
- 冲突预兆

### 二、中段（60%）

必须包含：
- 情绪升级
- 关系变化
- 欲望推进
- 至少一个冲突点

### 三、后段（20%）

必须包含：
- 冲突爆发
- 信息揭露
- 反转（可选）

### 四、结尾（10%）

必须包含：
- 强钩子
- 留白
- 制造"想读下一章"的欲望

---

## 章节自检

写完检查：

- [ ] 开头有没有钩子？
- [ ] 中段有没有情绪升级？
- [ ] 冲突是否足够强？
- [ ] 有没有推进关系/剧情？
- [ ] 结尾有没有留钩？
- [ ] 有没有AI味需要消除？

---

## 章节字数参考

| 类型 | 字数 |
|------|------|
| 短篇 | 3000-5000 |
| 长篇单章 | 2000-3000 |
| 爆款章节 | 2500-3500 |

## 情绪节奏图

```
开头：↑ 钩子引入
中段：↗ 情绪攀升
     ↗ 冲突出现
     ↗ 关系变化
     ↗ 欲望推进
后段：↑↑ 冲突爆发
     ↑↑ 信息揭露
结尾：↓ 情绪余韵
     → 留钩
```
