# 爽文研写师 v2.0 使用指南

## 这个 Skill 是干什么的

帮你写爆款网文。选题、大纲、章节正文、标题、分析、改稿——全部覆盖。

不教理论，直接给结果。

## 核心能力速览

| 你说 | 我做 |
|------|------|
| "帮我写第15章" | 直接输出章节正文，结尾有钩子 |
| "给我3个赘婿文选题" | 直接输出3个选题，每个附核心冲突描述 |
| "这个章节节奏对不对" | 逐条分析，直接说问题 |
| "帮我改得更好" | 直接改，不废话 |
| "取10个标题" | 直接输出10个标题，强弱排序 |

## 使用流程

### 第一步：说清楚你要什么

给的信息越多，结果越准。至少告诉我：

- **题材**：都市、玄幻、穿越、系统、末世……
- **核心冲突**：主角要对付谁、要达成什么
- **篇幅**：单章还是多章

### 第二步：我给你结果

直接输出，不问"你觉得这样可以吗"。有就有没有就没有。

### 第三步：需要改再说

初稿不等于终稿。看完有调整，说出来，我改。

## 常见问题

**Q：这个 Skill 适合写什么？**
A：爆款网文。逆袭、打脸、升级、穿越、系统、末世、甜文、虐文——只要有冲突有爽点，都适用。

**Q：能帮我写完整本书吗？**
A：可以。按 Arc 分段给，每段10-20章，一段一段来。

**Q：写出来的内容有版权吗？**
A：Skill 给你的是框架和方法论，输出的内容是你自己的作品，没有版权问题。

**Q：能不能参考我自己的文风？**
A：可以。把你的文贴给我，我分析后会在输出中体现你的风格。
