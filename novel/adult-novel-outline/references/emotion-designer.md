# 情绪目标设计师 v2.0

## 核心公式

**情绪峰值 ＝ 压迫程度 × 反转爽感 × 身份差**

三个变量同时拉高，情绪峰值才能爆。任何一项拖后腿，整体效果打折扣。

## 爽点类型速查表

| 爽点类型 | 触发条件 | 情绪强度 | 适用场景 |
|---------|---------|---------|---------|
| **打脸爽点** | 压迫后反击，反派颜面尽失 | ★★★★★ | 打脸、反击、逆袭 |
| **身份曝光爽点** | 前期隐瞒身份/实力，事后曝光 | ★★★★★ | 马甲文、隐藏大佬 |
| **逆袭爽点** | 弱势翻盘，以小博大 | ★★★★☆ | 废柴逆袭、绝地翻盘 |
| **团宠爽点** | 多方势力同时为同一目标让步 | ★★★★☆ | 甜文、团宠 |
| **系统奖励爽点** | 完成任务/击败对手，获得即时奖励 | ★★★☆☆ | 升级流、系统文 |
| **误会消除爽点** | 长期误解被澄清，情感爆发 | ★★★☆☆ | 情感虐恋、和解 |
| **独占/争夺爽点** | 多方争夺稀缺资源，主角最终独占 | ★★★★☆ | 商战、夺宝、感情 |
| **能力觉醒爽点** | 隐藏能力/血统/记忆被激活 | ★★★★☆ | 玄幻、异能、都市 |
| **复仇爽点** | 隐忍后实现对等或超额报复 | ★★★★★ | 复仇文、虐渣 |
| **反差爽点** | 前期弱小/低调 vs 后期强大/高调 | ★★★★☆ | 扮猪吃虎、马甲 |

## 情绪曲线模板

### 短篇单章曲线（1000-3000字）

```
第1段（15%）：建立压迫
第2段（25%）：加压/资源枯竭
第3段（20%）：绝境/被打压到谷底
第4段（20%）：反转触发
第5段（20%）：爽点爆发 + 钩子
```

### 中篇弧线（3-10章）

```
第1-2章：建立目标 + 初次压迫
第3-4章：压迫升级 + 盟友流失
第5-6章：谷底 + 暗中积蓄力量
第7-8章：反转信号 + 新冲突介入
第9-10章：大高潮爽点 + 胜利 + 新钩子
```

### 长篇多 Arc 曲线

```
Arc 1（10-20章）：建立世界 + 第一个小 Boss + 第一个大爽点
        ↓
过渡（2-3章）：休整 + 埋下更大冲突
        ↓
Arc 2（20-30章）：更大压迫 + 更强 Boss + 爽点升级
        ↓
过渡（2-3章）
        ↓
Arc N：终局 + 最高潮 + 收尾
```

## 情绪密度配置

| 篇幅 | 最小爽点数 | 推荐爽点数 | 两次爽点最大间距 |
|------|-----------|-----------|----------------|
| 短篇单章 | 2 | 3 | 1000字 |
| 中篇（4-10章） | 5 | 7 | 1500字 |
| 长篇（10+章） | 12 | 15+ | 2000字 |

**警告**：超过最大间距没有爽点，读者已经开始流失。

## 压迫值构建指南

**压迫值四维度**：

1. **物理压迫**：生命威胁、囚禁、追杀、剥夺生存资源
2. **社会压迫**：舆论毁灭、身份抹杀、孤立、社死
3. **情感压迫**：被最信任的人背叛、爱情被践踏、亲情断绝
4. **尊严压迫**：公开羞辱、践踏底线、被踩在脚下

**压迫值叠加原则**：
- 单维度压迫 → 情绪强度 1x
- 两个维度叠加 → 情绪强度 2.5x
- 三个维度叠加 → 情绪强度 5x
- 四个维度叠加 → 情绪强度 10x（终局Boss战可用）

## 爽点叠加公式

**单章爽点公式**：
```
爽点总强度 = 基础爽点 × 身份差系数 × 代价系数
```

- 基础爽点：打脸（1.0）、身份曝光（1.2）、逆袭（0.9）
- 身份差系数：普通人vs首富（3.0）、普通人vs权贵（2.0）、权贵vs权贵（1.2）
- 代价系数：付出了真实代价（2.0）、轻易获得（0.5）

**多爽点叠加**：
- 2个爽点同章出现 → 总强度 × 1.5
- 3个爽点同章出现 → 总强度 × 2.0
- 但要避免爽点连发造成审美疲劳

## 断章三原则

1. **断在高看点**：断在马上要揭晓、马上要发生、马上要反转的地方
2. **禁止的断章位置**：事件已经讲完、情绪已经平复、结果已经揭晓
3. **钩子强度**：让读者不说"明天再看"而说"我现在就要知道"
