## 三、核心工作流：从大纲到细写

### 3.1 第一步：生成故事大纲

**输入**（对 Agent 说）：
> "生成霸总×秘书的大纲，35章，重点：强取甜宠、办公室禁忌、后期有危机冲突"

**输出**：完整故事框架
- 每章剧情概要
- 角色背景与欲望弧线
- H戏节点规划（哪些章有H、强度等级）
- 主线与情欲线交叉推进图

### 3.2 第二步：规划欲望弧线

**输入**：
> "为女主规划完整的欲望弧线，从抵抗到臣服，分4个阶段"

**输出**：
- 每个阶段的心理变化节点
- 对应H戏的叙事功能（这场H"改变了什么"）
- 禁忌递进框架（每场比上一场增加了什么尺度）

### 3.3 第三步：单场H戏精细写作

**输入**：
> "写第15章H戏：女主第三次H，从被动到主动迎合，强度四星，羞耻Play + 三轮Edging"

**输出**：完整章节
- 四阶段结构完整（前戏→升温→高潮→余韵）
- 多感官描写自然交替
- Edging节奏精准控制
- 情感与肉戏同步推进

## 四、单场H戏四段式结构

每场完整H戏必须包含四个阶段，形成欲望释放的完整闭环：

### 4.1 阶段比例

| 阶段 | 比例 | 核心任务 | 字数参考（3000字场） |
|------|:----:|---------|:-------------------:|
| **前戏铺垫** | 20% | 建立"不得不发生"的必然性 | ~600字 |
| **升温试探** | 25% | 从日常进入性状态，确认意图 | ~750字 |
| **高潮释放** | 35% | 感官过载，完成心理转折 | ~1050字 |
| **余韵收束** | 20% | 处理心理余韵，埋伏笔 | ~600字 |

### 4.2 四阶段核心技法

#### 前戏（20%）— 建立叙事必然性

**任务**：让读者清楚——为什么是"现在"、为什么是"这个人"、为什么"不能停"。

| 技法 | 说明 |
|------|------|
| 空间即心理 | 阳台=暴露风险，办公室=权力压制，卧室=亲密许可 |
| 肢体暗示 | 将性张力伪装成日常动作（指尖触碰、弯腰走光、坐同一条沙发） |
| 五感铺垫 | 灯光/气味/声音暗示情感状态 |
| 障碍设置 | 外部（他人在场/时间紧迫）或内部（道德挣扎/骄傲恐惧） |

#### 升温（25%）— 破界瞬间

**任务**：从日常状态进入性状态，确认"第一个意图明确的身体接触"。

| 技法 | 说明 |
|------|------|
| 破界瞬间 | 放慢节奏，用几行文字写第一个明确的性意图动作 |
| 对话桥接 | 一句对话完成心理转折（挑逗/试探/确认） |
| 感官升级 | 从"暗示"升级到"反应"（脸红/体液/声音失控） |
| 第一轮Edging | 进入正题前设置第一个边缘点 |

#### 高潮（35%）— 感官过载

**任务**：多种感官同时发生、相互增强，完成本场最核心的叙事推进。

| 技法 | 说明 |
|------|------|
| 感官轮切 | 视觉→触觉→听觉→内在感知，环环相扣 |
| 短句加速 | 高潮临界点用碎句制造节奏冲击 |
| 多轮Edging | 每轮要有不同的心理崩溃描写 |
| 三层隐喻 | 生理层+情感层+哲学层叠加 |

#### 余韵（20%）— 情感收束

**任务**：从性状态回到日常状态，留下心理裂痕，埋伏笔。

| 技法 | 说明 |
|------|------|
| 身体后劲 | 用生理延迟反应证明刚才发生了什么（腿软/颤抖/酥麻） |
| 情感对话 | 每句事后对话同时承担至少两种功能 |
| 日常对照 | 一个日常动作将场景拉回地面（一根烟/收拾衣物） |
| 留白转身 | 永远让一个人先转身，让另一个人在背后看着 |

## 五、Edging系统

Edging（边缘控制）是成人向小说最重要的节奏工具——让读者知道角色快到了，但选择停下来，制造"累积感→挫折感→更强爆发"的张力落差。

### 5.1 轮数配置

| 强度 | Edging轮数 | 每轮写法重点 |
|------|-----------|-------------|
| ☆☆ | 1轮 | 进入前试探 |
| ☆☆☆ | 2-3轮 | 每轮不同反应 |
| ☆☆☆☆ | 4-5轮 | 心理弧线同步崩溃 |
| ☆☆☆☆☆ | 6轮+ | 跨章Edging，本场不释放 |

### 5.2 Edging写法阶段示例

**第一轮：崩溃边缘**
> 她的指甲掐进他肩膀。"快……"  
> 他停了。  
> 她几乎要哭出来。

**第二轮：主动求**
> "求你……"  
> 她从没说过这个字。  
> 他低笑，继续。

**第三轮：放下尊严**
> "我是你的……"  
> 声音软得像要化掉。

### 5.3 Edging结束方式

| 方式 | 说明 |
|------|------|
| 最终释放 | 第五次边缘后允许崩溃，哭喊着到达 |
| 跨章Edging | 电话响了——断在最强点，留下最强钩子 |

## 七、多感官描写技法

每场高能戏（☆☆☆以上）至少调动四种感官：

### 7.1 五感速查

| 感官 | 写法要点 | 常见错误 |
|------|---------|---------|
| **视觉** | 光影变化、体液动态、表情失控 | 只写静态身体数据 |
| **听觉** | 喘息变化、撞击声、水声 | 无意义呻吟堆砌 |
| **触觉** | 温度差、质感、压力变化 | 跳过前戏直接插入 |
| **嗅觉** | 体味、汗液、麝香、私处气味 | 过度使用无冲击力 |
| **味觉** | 亲吻、红酒味、精液咸涩 | 用场必须有功能 |

### 7.2 感官交织六大技法

| 技法 | 操作 | 示例 |
|------|------|------|
| **轮切** | 不同感官快速交替 | "手指探入。湿。她咬住下唇。紧。窗外有人在敲门。" |
| **主客切换** | 主动方触觉→被动方感受 | "他感到被紧紧吸住"+"她感到自己被撑开" |
| **对比放大** | 不相关画面并置产生第三含义 | "她穿着上班的白衬衫，但被撩到了锁骨以上" |
| **缺失强化** | 省略一种感官让其他更敏锐 | "她什么都看不见——蒙着眼。只有他的呼吸声越来越近" |
| **短句加速** | 高潮期用破碎短句 | "顶。再顶。深一点。不要停。啊——" |
| **留白艺术** | 写到边缘就停，不写尽 | "她快到了。他也感觉到了。然后他停下来了。" |

### 7.3 三层隐喻法

每个核心描写建议叠加三层：

```
动作：她紧紧夹住他

第一层（生理）：阴道壁痉挛般收缩，像溺水者抓住浮木
第二层（情感）：她在用身体说"不要走"，比任何话都诚实
第三层（存在）：那是两个人唯一一次完全放弃防备的时刻
```

## 十一、常见问题

**Q：如何决定一场H戏的强度？**  
A：根据欲望弧线阶段决定。初期强度低（☆☆），冲突爆发期最高（☆☆☆☆☆）。参考 pacing-guide.md 的节奏能量曲线。

**Q：Kink是不是越多越好？**  
A：不是。☆☆☆以下建议1-2个，☆☆☆☆☆建议3-4个，且必须主次分明、组合有逻辑。Kink服务于叙事，不是炫技。

**Q：五感是不是每次都要全部用上？**  
A：高潮阶段必须覆盖4种以上感官，但前戏和余韵可以侧重2-3种。选感官根据场景类型决定——户外场景侧重听觉（紧张压抑），调教场景侧重触觉（痛感与快感混合）。

**Q：Edging轮数怎么决定？**  
A：低强度（☆☆☆）2-3轮，高强度/调教（☆☆☆☆）4-7轮。跨章节Edging（断在最强点）是制造追读钩子的利器。

**Q：每场H戏必须推进欲望弧线吗？**  
A：重要场次（第一次、关系质变场）必须有明确的叙事推进。日常场次可以相对轻松，但也要有至少一个小的变化点。

**Q：如何写好事后余韵？**  
A：余韵的三大功能：①用身体后劲证明发生了什么（腿软/颤抖）；②对话收束情感（每句至少两层含义）；③为下一场埋伏笔。参考 chapter-format.md 的余韵写法。
