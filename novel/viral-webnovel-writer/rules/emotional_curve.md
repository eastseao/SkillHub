# 情绪曲线控制规则

情绪曲线是让读者欲罢不能的核心。

---

## 📐 标准情绪曲线

### 单章情绪曲线

```
高点（爽/虐）
     ↑
    / \
   /   \
  /     \        ← 爽点峰值
 /       \
/         \
───────────→ 时间
↑         ↑
开局     断章
```

**标准节奏**：
压迫 → 误解/打压 → 反击 → 爽点 → 悬念

### 多章情绪曲线

```
情绪强度
    ↑    ****           ****
    |   *    *         *    *        ****   ****
    |  *      *       *      *      *    * *    *
    | *        *     *        *    *      *      *
    |*          *****          ****          *****
    +----------------------------------------→ 章节
      章节1    章节2    章节3    章节4    章节5
```

每个章节有自己的小高潮，整本书有大高潮。

## 🔥 爆款情绪公式

### 核心公式

```
情绪峰值 = 压迫程度 × 反转爽感 × 身份差
```

**压迫程度**：越强越爽
- 普通人 → 被羞辱 → 压迫值：高
- 废物 → 被当众羞辱 → 压迫值：极高

**反转爽感**：越强越爽
- 普通反击 → 一般爽感
- 当众打脸 → 强爽感
- 全网震惊 → 极强爽感

**身份差**：越大越爽
- 普通人 vs 权贵
- 废物 vs 天才
- 乞丐 vs 帝王

## 📊 情绪类型

### 爽的情绪

1. **打脸爽**：当众羞辱 → 反转打脸
2. **逆袭爽**：弱势 → 反杀
3. **升级爽**：获得能力/地位
4. **复仇爽**：报仇雪恨
5. **装逼爽**：展示隐藏实力
6. **打脸爽**：揭穿小人

### 虐的情绪

1. **误解虐**：被冤枉
2. **失去虐**：失去重要的人/物
3. **背叛虐**：信任的人背叛
4. **无力虐**：想改变却无法改变
5. **牺牲虐**：为了某事牺牲自己

### 甜的情绪

1. **暧昧甜**：感情升温
2. **保护甜**：被保护
3. **并肩甜**：共同战斗
4. **承诺甜**：海誓山盟

## 🎯 情绪曲线设计

### 每章必须有情绪

- 最低要求：1个爽点/虐点
- 标准要求：2个爽点/虐点
- 优秀要求：3个以上+情感共鸣

### 情绪必须叠加

- 打脸 + 逆袭 = 双重爽
- 误解 + 揭穿 = 爽感翻倍
- 升级 + 打脸 = 爽感爆炸

### 情绪必须有节奏

- 不能全程高能（会审美疲劳）
- 不能全程平淡（会弃读）
- 高低起伏，张弛有度

---

## 🚫 禁止的情绪问题

### 禁止全程爽

- 会审美疲劳
- 爽点贬值
- 读者麻木

### 禁止全程虐

- 会弃读
- 情绪压抑
- 负面反馈

### 禁止情绪断层

- 不能突然从爽变平
- 不能突然从虐变平
- 必须有平滑过渡

### 禁止情绪不合理

- 不能突然无敌
- 不能突然降智
- 不能突然圣母
