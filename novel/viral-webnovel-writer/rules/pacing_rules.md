# 节奏控制规则

快节奏是爆款网文的核心。

---

## 📐 基础节奏规则

### 每300字必须有推进

- 不能超过300字没有事件发生
- 每段必须推动剧情或揭示信息
- 禁止"填充式"描写

### 每章必须1次情绪爆点

- 每章必须有一个"爽点"或"虐点"
- 情绪爆点必须在章节后半段
- 爆点可以是：打脸/逆袭/背叛/揭露/升级

### 每3章必须一次大反转

- 每3章至少一个大反转
- 反转可以是：身份/认知/力量/关系/局势

---

## 📊 章节节奏模板

### 标准章节（1500-2000字）

```
0-300字：开局冲突/压迫
  建立当前危机/困境
  主角面临压力

300-600字：冲突升级
  矛盾爆发
  被打压/被羞辱

600-1000字：转机/反转
  隐藏力量/信息
  局势开始变化

1000-1500字：爆发爽点
  打脸/逆袭/升级
  情绪高潮

1500-2000字：悬念收尾
  断章钩子
  留下期待
```

### 爆款章节（3000-5000字）

```
0-300字：钩子/悬念
  上章结尾延续
  快速进入冲突

300-600字：第一波冲突
  建立压迫
  情绪铺垫

600-900字：意外发生
  第一个反转
  局势转变

900-1200字：高潮准备
  第二个反转
  爽点前奏

1200-1800字：核心爽点
  主要打脸/逆袭
  情绪峰值

1800-2400字：爽点延续
  后续影响
  周围反应

2400-3000字：反派的回应/新威胁
  留下钩子
  悬念收尾

3000-5000字：大章节专用
  重大转折/势力变化
  史诗级爽点
```

## 🚫 节奏禁止事项

### 禁止的节奏问题

1. **慢热**：前10章没有爆点
2. **平铺**：没有冲突的日常
3. **拖沓**：超过500字没有事件
4. **断链**：章节之间没有连接
5. **虎头蛇尾**：开局精彩后面拉胯
6. **无规律高潮**：爽点分布不均

### 常见节奏问题修复

**问题1：铺垫太长**
- 修复：删除第1段，直接进入冲突
- 修复：将铺垫压缩到100字内

**问题2：节奏拖沓**
- 修复：删除所有"然后..."
- 修复：压缩连续动作描写

**问题3：冲突不够**
- 修复：增加一个"被打压"场景
- 修复：增加一个"当众羞辱"场景

## 📈 节奏自检表

写完章节后检查：
- [ ] 前300字有冲突吗？
- [ ] 每300字有推进吗？
- [ ] 有情绪爆点吗？
- [ ] 爽点够爽吗？
- [ ] 结尾有钩子吗？
- [ ] 节奏够快吗？

---

## 🔥 爆款节奏公式

```
开局（钩子） × 冲突（施压） × 反转（意外） × 爽点（爆发） × 悬念（断章）
= 爆款章节
```

每个元素都必须有，缺一不可。
