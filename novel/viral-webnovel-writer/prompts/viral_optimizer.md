# 爆改优化器（70→90分）

将任意小说内容优化为爆款版本。

---

## 🎯 优化目标

- 提升冲突密度 +200%
- 增加反转点
- 强化羞辱/逆袭/权力差
- 删除所有"无信息句"
- 情绪曲线峰值化

---

## 📐 优化维度

### 1️⃣ 冲突密度优化

**问题**：冲突太少，节奏拖沓
**优化**：
- 删除无冲突段落
- 压缩铺垫时间
- 增加压迫场景
- 制造更多矛盾

**公式**：
```
原：铺垫 → 事件
改：压迫 → 反转 → 爽点
```

### 2️⃣ 反转密度优化

**问题**：没有反转，平淡无奇
**优化**：
- 每个场景增加1个反转点
- 增加身份反转
- 增加认知反转
- 增加力量反转

**模板**：
```
你以为[A]，实际是[B]
你看到[表象]，背后是[真相]
```

### 3️⃣ 情绪强度优化

**问题**：情绪不够强烈
**优化**：
- 增加打脸场景
- 增加逆袭场景
- 增加权力碾压
- 增加羞辱→反转

**公式**：
```
羞辱程度 × 反转爽感 = 情绪峰值
```

### 4️⃣ 删除冗余

**必须删除**：
- 无意义的环境描写
- 无冲突的心理描写
- 闲聊式对话
- 背景介绍（开局后）
- 重复信息

**原则**：每个字必须推进剧情

### 5️⃣ 钩子强化

**问题**：结尾没有吸引力
**优化**：
- 增加悬念钩子
- 增加冲突中断
- 增加情绪爆发点
- 增加伏笔暗示

## 🔥 爆改示例

### 示例一：平淡开头→爆款开头

**原版**：
"李四是一个普通人，他生活在一个小村庄里。"

**爆改版**：
"废物。李四蹲在墙角，听着全村的嘲笑。三年前，他是天才；三年后，他是废物。而今天，是他被未婚妻退婚的日子。"

### 示例二：平淡冲突→爆款冲突

**原版**：
"王五和李六发生了争吵。"

**爆改版**：
"'就凭你？'王五冷笑，抬手就是一巴掌，'你知道我爹是谁吗？'李六没有躲。他只是平静地抬起头，眼神深处，闪过一丝寒光。"
