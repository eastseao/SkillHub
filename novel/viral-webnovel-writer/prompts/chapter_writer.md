# 章节写作引擎

写章节时必须遵循以下规则：

## 📐 结构规范

每800-1500字一个小冲突
每段推动剧情，不描述环境
结尾必须留悬念

## 🔥 标准章节结构

```
开局压迫（0-300字）
  ↓ 建立当前困境/危机
冲突升级（300-600字）
  ↓ 压迫加剧，矛盾爆发
反转（600-1000字）
  ↓ 意外发生/隐藏真相揭露
爽点（1000-1300字）
  ↓ 主角逆袭/打脸/获得
悬念收尾（1300-1500字）
  ↓ 断章，留下钩子
```

## ✍️ 写作规则

### 段落规则

- 每段不超过100字
- 每段必须有信息推进
- 禁止纯描写段落
- 禁止环境渲染占用超过5%

### 对话规则

- 对话必须有目的（推进/揭示/施压）
- 禁止闲聊式对话
- 每句台词必须有潜台词
- 对话推进冲突，不是闲聊

### 描写规则

- 心理描写≤10%
- 环境描写≤5%
- 动作描写为主
- "展示"而非"讲述"

## 🎯 每章必须包含（至少1个）

- 打脸（当众羞辱→反转）
- 逆袭（弱势→反杀）
- 误会升级（矛盾加剧）
- 权力碾压（高层打压→反击）
- 隐藏身份曝光（震惊全场）
- 系统奖励/升级（获得新能力）
- 情感冲击（背叛/感动/震惊）

## 🚫 禁止事项

- 无冲突的平铺直叙
- 大段背景说明
- 无意义的心理独白
- 环境描写超过10%
- 结尾没有悬念（除非大章节结尾）
- 超过5个自然段无推进

## 📊 字数节奏

- 短章节：800-1200字（日常/过渡）
- 标准章节：1500-2000字（正常节奏）
- 大章节：2500-3500字（高潮章节）
- 爆款章节：3000-5000字（重要转折）

## 🔗 章节钩子模板

### 钩子类型

1. **冲突悬念**：刚要动手，被打断...
2. **身份悬念**：[某人]似乎知道了他的秘密...
3. **危机悬念**：他不知道，死亡正在逼近...
4. **情感悬念**：她不知道，这是他们最后一次见面...
5. **伏笔悬念**：没有人注意到，天空中的异象...

### 钩子公式

```
[冲突中断/新信息/意外发现] + [情绪诱导] + [留白]
```

## 📝 输出格式

```markdown
# 第X章 标题

[正文]

---

【本章爽点】：打脸/逆袭/系统奖励/身份曝光
【下章钩子】：...
【章节字数】：XXX
```

## 🔄 自检清单

写完章节后自检：
- [ ] 有无冲突？
- [ ] 有无爽点？
- [ ] 有无悬念结尾？
- [ ] 描写占比≤15%？
- [ ] 每段有推进？
- [ ] 对话有目的？
