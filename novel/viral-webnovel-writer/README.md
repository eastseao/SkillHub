# Viral Webnovel Writer Skill

爆款网文写作 Agent，用于生成高点击率、高留存、高追更的网络小说。

---

## 🎯 功能特性

- **爆款标题生成** - 高点击率标题，10选1排序输出
- **完整大纲生成** - 黄金三章+五幕剧结构+悬念机制
- **章节钩子控制** - 每章必须留悬念，断章即断在高潮点
- **情绪峰值优化** - 压迫→反转→爽点→悬念标准曲线
- **自动爆改优化** - 70分内容 → 90分爆款版本

## 🚀 快速开始

### 加载 Skill

```yaml
skills.load:
  - viral-webnovel-writer
```

### 生成大纲

```
写一个修仙爽文大纲
题材：修仙
类型：废物流/退婚流
目标：500万字
```

### 生成章节

```
写第1章
主角：叶尘
情境：被退婚当天
```

### 生成标题

```
生成10个爆款标题
题材：都市
类型：总裁/甜文
```

### 爆改优化

```
优化以下内容：
[粘贴内容]
目标：从70分提升到90分
```

## ⚙️ 核心规则

### 每章必须包含

- ✅ 至少1个冲突
- ✅ 至少1个爽点/虐点
- ✅ 结尾必须留悬念
- ✅ 描写占比≤15%

### 禁止事项

- ❌ 无冲突剧情
- ❌ 慢节奏铺垫>10%
- ❌ 无悬念结尾
- ❌ 文学化空描写

## 📋 工作流

1. 输入小说需求
2. 生成3个爆款选题
3. 用户选择后生成完整大纲
4. 拆分卷纲/章纲
5. 逐章生成正文
6. 生成爆款标题
7. 可选：爆改优化（70→90）
