# 结尾库

## 一、主流结局类型

### 1. 圆满型（HE）

**特点：** 甜、幸福、大团圆

**适用题材：** 甜宠、治愈、爽文

**情绪关键词：**
幸福、圆满、甜蜜、美满

**结尾模板：**
```
"我们结婚了。
在那个春天。
樱花树下。
他说："这辈子，你是我的了。"
我说："下辈子，你也是。"
我们笑着。
笑着笑着。
眼泪流了下来。
是幸福的眼泪。"
```

---

### 2. 留白型（开放式）

**特点：** 不说透、留悬念、想象空间

**适用题材：** 深度文、现实向

**情绪关键词：**
意犹未尽、未完待续

**结尾模板：**
```
"他走了。
我看着他的背影。
很久，很久。
风吹过。
樱花落了一地。
我没说话。
有些故事。
不需要结局。
有些结局。
不需要说透。"
```

---

### 3. 反转型

**特点：** 最后一个反转、震撼

**适用题材：** 悬疑、复仇、烧脑

**情绪关键词：**
震惊、意外、细思极恐

**结尾模板：**
```
"他死了。
所有人都以为是他杀了我。
只有我知道。
是我杀了他。
从头到尾。
都是我在操纵。
而现在——
他死了。
我自由了。
终于。"
```

---

### 4. 虐心型（BE）

**特点：** 意难平、遗憾、心疼

**适用题材：** 深度虐文、现实向

**情绪关键词：**
遗憾、意难平、心碎

**结尾模板：**
```
"她走了。
去了很远的地方。
他找了她很久。
很久。
再也没找到。
多年后。
他路过一家花店。
看到一个背影。
很像她。
他愣了一下。
笑了笑。
转身离开。
有些人。
错过了。
就是一辈子。"
```

---

### 5. 彩蛋型

**特点：** 圆满 + 番外彩蛋

**适用题材：** 通用

**情绪关键词：**
甜蜜、温馨、满足

**结尾模板：**
```
"【正文完】

【番外·十年后】

"爸爸，妈妈！"
女儿跑过来。
他牵起她的手。
她站在阳光下。
笑着。
一切都刚刚好。
——END——

（谢谢你们，陪他们走到这里。）"
```

## 二、知乎热门结局

### 追妻火葬场结局

```
"他跪了一夜。
第二天。
他没起来。
他跪着。
跪着。
笑着哭。
他知道我不会回头了。
他认了。
这就是他的结局。
他活该。"
```

### 重生复仇结局

```
"她赢了。
赢得彻底。
那些人，一个一个。
都付出了代价。
她站在高处。
看着他们。
笑了笑。
不是她狠。
是她们先动手的。
现在。
该她了。"
```

### 甜宠结局

```
"他说："嫁给我。"
没等她回答。
他单膝下跪。
戒指戴上她的手指。
"你这辈子，跑不掉了。"他说。
她笑了。
"谁要跑？"她问。
他愣了。
然后他也笑了。
笑得很开心。
"我就知道。"他说。
"你也是爱我的。"
"
```

## 三、结尾写作技巧

### 情绪到位

```
结尾是情绪最高点
需要把情绪推向极致
让读者有共鸣
```

### 收束伏笔

```
所有埋下的伏笔
在结尾要有回应
让读者有"原来如此"的感觉
```

### 留白艺术

```
不必说透
留点空间给读者
有时候不说比说出来更好
```

### 金句点睛

```
结尾用一句金句升华
让读者记住
这是最好的结尾方式
```

## 四、结尾禁忌

```
❌ 烂尾
❌ 强行HE
❌ 前后矛盾
❌ 说不清楚
❌ 太仓促
❌ 无情绪高潮
```
