# 情绪库

## 一、八大核心情绪

### 1. 压抑

**定义：** 情绪被压制，不释放，憋着

**触发场景：**

- 女主被误解
- 被欺负不敢反抗
- 付出不被看见
- 处于弱势地位

**情绪关键词：**
憋屈、委屈、心酸、无奈、隐忍、憋着、压着

**经典情绪句：**
```
"我没说话。
笑了笑。
继续做我的事。
三年了，早习惯了。"
```

---

### 2. 委屈

**定义：** 被冤枉、不被理解、不被珍惜

**触发场景：**

- 被冤枉出轨/偷东西
- 付出被当作理所当然
- 真心被辜负
- 明明没错却被责怪

**情绪关键词：**
委屈、心酸、想哭、凭什么、为什么是我

**经典情绪句：**
```
"我没有。
我真的没有。
可是没人信我。
连他都不信。"
```

---

### 3. 愤怒

**定义：** 压抑到极限后的爆发

**触发场景：**

- 被触及底线
- 真相被揭开
- 被逼到绝路
- 发现被欺骗

**情绪关键词：**
气死了、凭什么、滚、滚远点、不配

**经典情绪句：**
```
"够了。
我听够了。
你别再说了。
我不想再忍了。"
```

---

### 4. 爽感

**定义：** 情绪释放，解气，过瘾

**触发场景：**

- 打脸成功
- 身份曝光
- 反转到来
- 复仇成功

**情绪关键词：**
爽、解气、过瘾、痛快、舒服、活该

**经典情绪句：**
```
"他脸色变了。
他没想到。
他以为我会哭。
我笑了。
我说：活该。"
```

---

### 5. 报复

**定义：** 以牙还牙，爽感加倍

**触发场景：**

- 反杀绿茶
- 让对方后悔
- 以其人之道还治其人之身
- 完美复仇

**情绪关键词：**
报应、活该、遭报应、后悔、晚了

**经典情绪句：**
```
"我说过。
会有这一天的。
你看，报应来了。
这滋味，好受吗？"
```

---

### 6. 后悔

**定义：** 错过、失去后才懂得珍惜

**触发场景：**

- 男主错过女主
- 失去后才发现爱
- 做错事后才后悔
- 追妻火葬场

**情绪关键词：**
后悔、晚了、来不及、如果、早知道

**经典情绪句：**
```
"她走了。
他才发现。
他错了。
他真的错了。
可是晚了。
来不及了。"
```

---

### 7. 虐恋

**定义：** 相爱却不能在一起，或互相折磨

**触发场景：**

- 误会太深
- 身份差距
- 家族反对
- 命运的捉弄

**情绪关键词：**
爱而不得、折磨、痛苦、舍不得、放不下

**经典情绪句：**
```
"我爱你。
可我不能要你。
越爱，越痛。
越痛，越爱。
我们，回不去了。"
```

---

### 8. 救赎

**定义：** 被治愈、被温暖、被救赎

**触发场景：**

- 被人真心疼爱
- 走出阴影
- 被理解被接纳
- 重获新生

**情绪关键词：**
治愈、温暖、幸福、值得、被爱、救赎

**经典情绪句：**
```
"他说：有我在。
他说：别怕。
他说：你是我的。
那一刻，我哭了。
原来，这就是被爱的感觉。"
```

## 二、情绪曲线模型

### 标准虐文曲线

```
压抑（30%）→ 委屈（20%）→ 愤怒（20%）→ 爆发（20%）→ 爽感（10%）
```

### 追妻火葬场曲线

```
虐（40%）→ 她走了（15%）→ 他后悔（15%）→ 追妻（20%）→ 圆满（10%）
```

### 甜宠文曲线

```
心动（20%）→ 暧昧（30%）→ 确认（20%）→ 阻碍（10%）→ 甜蜜（20%）
```

### 重生复仇曲线

```
被害（10%）→ 重生（10%）→ 复仇（50%）→ 打脸（20%）→ 圆满（10%）
```

## 三、情绪锚点

### 催泪锚点

- 离别/死亡
- 被至亲伤害
- 错过/遗憾
- 牺牲/放弃

### 燃点锚点

- 逆袭成功
- 打脸时刻
- 身份曝光
- 翻盘瞬间

### 甜点锚点

- 宠溺瞬间
- 告白时刻
- 亲吻拥抱
- 幸福日常

### 虐点锚点

- 误会
- 错过
- 背叛
- 失去

---

## 四、情绪转换词

### 压抑→释放

```
忽然 → 终于 → 那一刻 → 爆发 → 眼泪
```

### 委屈→愤怒

```
凭什么 → 不公平 → 我不甘心 → 够了 → 爆发
```

### 后悔→追

```
发现 → 晚了 → 后悔 → 追 → 求
```

### 虐→甜

```
离开 → 相遇 → 被爱 → 治愈 → 圆满
```

## 五、知乎情绪节奏

```
情绪要强 → 不要平淡 → 每段要有情绪点
短句为主 → 情绪外化 → 对话推进
留白艺术 → 不要写太满 → 让读者脑补
```
