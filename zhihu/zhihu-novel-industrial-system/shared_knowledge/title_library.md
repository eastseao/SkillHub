# 标题库

## 一、知乎风标题

### 身份反差型

```
"全班都以为我很穷"
"全公司都以为我是实习生"
"所有人都以为我是替身"
"他不知道我是隐藏大佬"
"他们都叫我穷学生，其实..."
"假千金，真大佬"
"我不是灰姑娘，我是..."
```

### 后悔追妻型

```
"我死后，他疯了"
"她走的那天，他跪了一夜"
"他哭着求我，我笑了"
"错过她，是我最大的遗憾"
"追妻火葬场，他烧成灰了"
"她不要他了，他才慌了"
"她消失后，他疯了"
```

### 情绪刺激型

```
"离婚后，总裁后悔了"
"全班都以为我很穷"
"婚礼当天，新郎逃了"
"他第一次求我，是下跪那天"
"她的葬礼，他没来"
"他的婚礼，我的葬礼"
```

### 反转型

```
"她以为她是赢家"
"他以为她离不开他"
"所有人都以为她会哭"
"我以为我是替身"
"他以为她好欺负"
"她以为她赢了"
```

## 五、标题句式模板

### 知乎句式

```
"我____，他____"
"____当天，____"
"他们都以为____，其实____"
"____后，____疯了"
"____年，____"
```

### 番茄句式

```
"____：____"（主副标题）
"____，____！"（感叹）
"我____，____"（主角+事件）
```

### 晋江句式

```
"____"（双字/诗意）
"____，____"（对仗）
"____几时休"（疑问）
```

## 七、爆款标题规律

### 三要素

```
✅ 情绪刺激
✅ 身份反差
✅ 反转悬念
```

### 公式

```
情绪 + 身份 + 反转 = 爆款标题
```

### 字数控制

```
知乎风：6-15字
番茄风：8-20字
晋江风：2-6字
起点风：8-20字
```

---

## 八、标题生成流程

```
1. 提取小说核心卖点
2. 确定标题风格（平台）
3. 套用句式模板
4. 添加情绪词
5. 检查是否吸引眼球
6. 优化至最佳
```
