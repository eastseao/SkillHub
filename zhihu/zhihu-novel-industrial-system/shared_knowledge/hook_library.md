# 钩子库

## 一、开篇钩子

### 身份反差类

```
"全班都以为我很穷"
"全公司以为我是实习生"
"所有人都以为我是替代品"
"他不知道我是他老板"
"我以为我是替身，结果我是白月光"
```

### 冲突开场类

```
"我结婚当天，新郎跑了"
"我妈的葬礼上，他没来"
"婚礼现场，我被抓了"
"产房门口，他选择了保小"
"他的婚礼，我的葬礼"
```

### 悬念开场类

```
"他疯了似的找我，找了三年"
"我死后，他一夜白了头"
"他不知道，我活不了多久了"
"所有人都说我死了，包括他"
"我消失后，他疯了"
```

### 反差开场类

```
"他第一次求我，是下跪那天"
"他从来不低头，直到那天"
"他以为我好欺负"
"她以为我好骗"
"他以为我会哭，我没哭"
```

## 二、标题钩子

### 情绪刺激型

```
"我死后，他疯了"
"她走的那天，他跪了一夜"
"他不爱你了，你还不知道？"
"离婚后，总裁他后悔了"
"错过她，是我最大的遗憾"
```

### 身份落差型

```
"全班都以为我很穷"
"全公司都以为我是实习生"
"他不知道我是隐藏大佬"
"他们叫我穷学生，其实我是..."
"假千金，真大佬"
```

### 反转型

```
"她以为他爱她，其实..."
"他以为她好欺负，没想到..."
"他以为她离不开他"
"所有人都以为她会哭"
"他不知道她已经不爱了"
```

### 后悔流型

```
"他哭着求她，她没回头"
"她不要他了，他才慌了"
"错过她，是我最大的错"
"他后悔了，可她不原谅"
"追妻火葬场，他烧成灰了"
```

## 三、章节钩子

### 悬念钩

```
"就在这时，门开了"
"他手机响了"
"她忽然看到了什么"
"他看她的眼神，变了"
"事情，远没那么简单"
```

### 反转钩

```
"等等，这个人是..."
"他没想到，她会这样说"
"反转来了"
"最不可能的人，出现了"
"她笑了，笑着笑哭了"
```

### 情绪钩

```
"那一刻，他心碎了"
"她终于爆发了"
"他后悔了"
"她哭得像个孩子"
"他的眼眶，湿了"
```

### 留白钩

```
"他没有说完那句话"
"她没有等到那个答案"
"门关上的一刻"
"他没有回头"
"故事，才刚开始"
```

## 四、结尾钩子

### 悬念结尾

```
"但她不知道，这只是开始"
"真正的考验，还在后面"
"而这一切，被监控拍了下来"
"她的身份，远不止那么简单"
"他的秘密，终于藏不住了"
```

### 情感结尾

```
"她笑了，他哭了"
"他们，终于走到了一起"
"爱，战胜了一切"
"原来，这就是答案"
"从此以后，再无遗憾"
```

### 反转结尾

```
"而她，才是那个猎人"
"但谁也没想到..."
"他，才是最大的变量"
"故事的结局，真相大白"
"但这不是结束，是开始"
```

### 开放式结尾

```
"她的眼神，望向远方"
"未完待续"
"命运，才刚刚开始"
"而他们..."
"留一个悬念给你们"
```

## 五、钩子强度分级

### ★★★★★ 顶级钩子

- 身份惊天反转
- 死亡/假死
- 追妻名场面
- 极致情绪爆发

### ★★★★☆ 强钩子

- 误会揭开
- 身份曝光
- 打脸时刻
- 救赎瞬间

### ★★★☆☆ 普通钩子

- 小反转
- 情绪波动
- 悬念留白
- 期待感

---

## 六、钩子组合公式

```
顶级钩子 = 身份反差 + 情绪刺激 + 反转
开篇钩子 = 冲突场景 + 悬念留白
章节钩子 = 意外发生 + 情绪递进
结尾钩子 = 悬念/反转 + 情感余韵
```
