# 结构分析规则库

## 一、盐选小说结构体系

### 短篇结构（1-3万字）

```
开篇：500字内必须出现第一个钩子
展开：每2000字一个小高潮
递进：情绪层层叠加
高潮：最后一个反转必须炸裂
结尾：留白或情绪余韵
```

### 中篇结构（5-10万字）

```
第一阶段（1-3万字）：建立人设 + 第一个冲突
第二阶段（3-6万字）：感情升温 + 虐点爆发
第三阶段（6-8万字）：真相揭开 + 追妻火葬场
大结局（8-10万字）：圆满/BE收尾
```

### 长篇结构（10万字以上）

```
第一卷：相遇与冲突（1-10万字）
第二卷：误会与虐恋（10-20万字）
第三卷：真相与追妻（20-30万字）
第四卷：圆满或新冲突（30万字+）
```

## 二、开篇结构模板

### 知乎风开篇公式

**公式一：冲突前置**

```
【场景】：直接呈现一个冲突场景
【人物】：女主处于弱势/困境
【钩子】：留下悬念或反转预兆

示例：
"结婚三年，他从未正眼看过我。
今天是我妈的葬礼，他没来。
却在白月光的朋友圈里，看到了他的身影。"
```

**公式二：人设反差**

```
【表层】：展示一个出人意料的场景
【反差】：暗示背后有隐情
【钩子】：引发好奇

示例：
"所有人都以为我是穷学生。
包括我的男友。
他不知道，我家保镖就站在楼下。"
```

**公式三：情绪冲击**

```
【压抑】：开篇即压抑/委屈/愤怒
【蓄力】：情绪积累
【钩子】：反转或爆发

示例：
"第99次加班到凌晨。
老板发来消息：'明天继续。'
我看了眼银行卡余额：287.43元。
想起老家等着我寄钱回去的爸妈。
笑了笑，继续工作。"
```

## 三、高潮结构设计

### 爆点分布规律

| 阶段 | 字数位置 | 爆点类型 | 强度 |
|------|----------|----------|------|
| 开篇 | 0-3000字 | 钩子类 | ★★★☆☆ |
| 第一波 | 3000-8000字 | 冲突类 | ★★★☆☆ |
| 小高潮 | 1-2万字 | 转折类 | ★★★★☆ |
| 中段 | 3-5万字 | 虐心类 | ★★★★☆ |
| 大高潮 | 6-8万字 | 逆转类 | ★★★★★ |
| 结局 | 8-10万字 | 爆发类 | ★★★★★ |

### 情绪高潮公式

```
压抑值累积 → 临界点 → 爆发 → 释放 → 余韵

示例：
"她以为他会解释。
等了一夜，没有一条消息。
第二天，她看到了热搜：
'某集团总裁与神秘女子共度春宵。'
配图是他的侧脸。
她关掉手机，
把病例单揉成一团——
晚期。"
```

## 四、章节结构模板

### 单章结构（2000-4000字）

```
开篇钩子（200字内）
    ↓
情节推进（800字）
    ↓
小反转/小高潮（1000字）
    ↓
情绪递进（800字）
    ↓
章节钩子（200字）← 留下悬念
```

### 黄金三行法则

**每章开头三行必须：**
1. 承接上文（钩子延续）
2. 明确场景
3. 制造期待

**每章结尾三行必须：**
1. 解决或升级当前冲突
2. 留下新悬念
3. 情绪到位

## 五、转折与反转技巧

### 小转折（每章必有）

```
平静场景 → 意外发生 → 情绪波动

示例：
"我以为今天会平静度过。
直到他推门进来。
身后，还牵着一个女人。"
```

### 中转折（每3-5章一次）

```
主角以为... → 事实是... → 认知颠覆

示例：
"我以为他不爱我。
我以为这三年只是我一厢情愿。
直到我翻到了他抽屉里的那本日记——
每一页，都是我的名字。"
```

### 大反转（全书高潮期）

```
以为的真相 → 真正真相 → 全部颠覆

示例：
"我以为我是替身。
我以为他心里只有她。
直到她拿着DNA报告来找我：
'你才是他妈亲生的。'
那一刻，我看到他的眼里，
第一次有了光。"
```

## 六、节奏把控

### 快节奏类型

**适用题材：** 复仇、打脸、爽文、悬疑

```
开篇：强冲突（500字内）
推进：2-3章一个反转
高潮：密集叠加
结尾：干脆利落
```

### 慢节奏类型

**适用题材：** 甜宠、治愈、成长

```
开篇：人设建立（1000字）
推进：细腻情感铺垫
高潮：情绪积累后的爆发
结尾：温暖收尾
```

### 张弛结合型

**适用题材：** 豪门、婚恋、现实情感

```
快：冲突戏、误会戏、打脸戏
慢：感情升温、暧昧戏、温馨戏
快：高潮爆发、真相揭露
慢：结局收尾、余韵
```

## 七、结尾结构设计

### 热门结尾类型

| 类型 | 特点 | 适用题材 |
|------|------|----------|
| 圆满型 | 甜、HE、大团圆 | 甜宠、治愈 |
| 留白型 | 开放式结局 | 深度文、现实向 |
| 反转型 | 最后一个反转 | 悬疑、复仇 |
| 虐心型 | 意难平、BE | 深度虐文 |
| 彩蛋型 | 圆满+番外彩蛋 | 通用 |

### 结尾公式

```
情绪最高点 → 稍缓 → 小波折 → 真正结局 → 余韵

示例：
"他单膝跪地。
戒指递到我面前。
我刚要伸手——
他的手机响了。
他皱眉看了眼来电显示，
脸色骤变。
'抱歉。'
他起身，快步离开。
我看着那枚戒指，
笑了笑，
捡起来，戴在自己手上。
'谁稀罕。'
然后转身，
走向了等在门口的那个人。"
```

## 八、结构自检清单

### 开篇检查

- [ ] 500字内有冲突
- [ ] 人物关系明确
- [ ] 钩子足够强
- [ ] 目标读者清晰

### 中段检查

- [ ] 每章有推进
- [ ] 每3章有反转
- [ ] 情绪曲线上升
- [ ] 配角有亮点

### 高潮检查

- [ ] 情绪达到顶点
- [ ] 反转够意外
- [ ] 逻辑自洽
- [ ] 读者有共鸣

### 结尾检查

- [ ] 收束所有伏笔
- [ ] 情绪到位
- [ ] 不烂尾
- [ ] 有余韵
