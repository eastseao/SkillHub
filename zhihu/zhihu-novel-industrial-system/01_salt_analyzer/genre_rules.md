# 题材分析规则库

## 一、女频题材体系

### 1. 豪门总裁类

**核心元素：**
- 总裁/大佬男主
- 契约婚姻/隐婚
- 误会虐恋
- 追妻火葬场

**标签组合：**
- 豪门 + 甜宠
- 豪门 + 虐恋
- 豪门 + 马甲
- 豪门 + 复仇

**常见套路：**
- 女主带球跑
- 男主失忆
- 女主假死
- 父母辈恩怨

**标杆作品特征：**
- 开头强冲突（捉奸/误会/退婚）
- 女主有隐藏身份
- 男主前期渣后期舔
- 配饭菜渣

---

### 2. 重生复仇类

**核心元素：**
- 重生归来
- 预知未来
- 复仇虐渣
- 逆天改命

**标签组合：**
- 重生 + 复仇
- 重生 + 甜宠
- 重生 + 创业
- 重生 + 婚恋

**常见套路：**
- 被害死 → 重生到关键节点
- 揭开虚伪面具
- 攻略前世错过的人
- 复仇计划步步为营

**标杆作品特征：**
- 开篇即重生
- 节奏快、不拖沓
- 反派智商全程在线
- 女主全程高能

---

### 3. 穿越架空类

**核心元素：**
- 魂穿/身穿
- 古代/异世
- 宫斗/宅斗
- 王爷/皇子

**标签组合：**
- 穿越 + 宫斗
- 穿越 + 医妃
- 穿越 + 团宠
- 穿越 + 种田

**常见套路：**
- 现代知识碾压古人
- 医术/毒术傍身
- 攻略冰山男主
- 养包子/养娃

**标杆作品特征：**
- 穿越有金手指
- 剧情反转多
- 感情线与事业线并重

---

### 4. 校园甜宠类

**核心元素：**
- 青梅竹马
- 学霸学渣
- 暗恋成真
- 毕业季

**标签组合：**
- 校园 + 甜宠
- 校园 + 暗恋
- 校园 + 治愈
- 校园 + 双向奔赴

**常见套路：**
- 男主暗恋多年
- 女主机缘巧合成为同桌
- 误会错过再重逢
- 从校服到婚纱

**标杆作品特征：**
- 心动戏要细腻
- 暧昧氛围拉满
- 无狗血、有糖分

---

### 5. 现实情感类

**核心元素：**
- 原生家庭
- 女性成长
- 两性博弈
- 社会议题

**标签组合：**
- 原生家庭 + 独立
- 婚姻 + 抉择
- 职场 + 情感
- 渣男 + 觉醒

**标杆作品特征：**
- 情感真实、戳心
- 有社会讨论度
- 女性成长主线清晰

---

## 二、男频题材体系

### 1. 都市修仙类

**核心元素：**
- 都市修仙
- 扮猪吃虎
- 强者回归
- 美女环绕

**标签组合：**
- 都市 + 修仙
- 赘婿 + 逆袭
- 神医 + 都市
- 兵王 + 都市

### 2. 玄幻玄幻类

**核心元素：**
- 废柴逆袭
- 升级打怪
- 宗门恩怨
- 神器觉醒

**标签组合：**
- 玄幻 + 穿越
- 玄幻 + 系统
- 玄幻 + 女帝

### 3. 悬疑灵异类

**核心元素：**
- 盗墓探险
- 灵异事件
- 悬疑推理
- 恐怖生存

---

## 三、题材识别流程

```
第一步：扫描标签
  ↓
第二步：确认核心主线（感情线/事业线/复仇线）
  ↓
第三步：识别核心爽点类型
  ↓
第四步：判断所处阶段（萌新期/成长期/爆发期）
  ↓
输出：题材画像
```

## 五、题材搭配公式

**爆款公式：**

1. **豪门 + 重生 + 追妻** = 王炸组合
2. **穿越 + 医妃 + 甜宠** = 古言热门
3. **校园 + 暗恋 + 治愈** = 口碑之选
4. **现实 + 原生家庭 + 成长** = 深度出圈
5. **系统 + 快穿 + 攻略** = 流量密码

**避雷组合：**

- 题材过于小众
- 爽点不明确
- 情绪输出混乱
- 三观过于极端
