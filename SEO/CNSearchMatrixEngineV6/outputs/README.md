# outputs

本目录用于存放系统生成的内容输出文件。

## 使用说明

每次运行系统生成的内容时，将输出文件保存到此目录。

## 文件命名规范

```
[日期]_[主题]_[平台].[扩展名]
示例：2024-01-15_智能锁_百度SEO.md
```

## 目录结构

```
outputs/
├── baidu_seo/          # 百度SEO内容
├── wechat/             # 微信公众号内容
├── xiaohongshu/        # 小红书内容
├── zhihu/              # 知乎内容
├── douyin/             # 抖音脚本
├── ai_search/          # AI搜索优化内容
├── reports/            # 分析报告
└── other/              # 其他输出
```

## 内容管理

- 定期整理输出文件
- 保持目录结构清晰
- 及时归档过期内容
