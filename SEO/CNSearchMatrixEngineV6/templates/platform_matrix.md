# 平台矩阵模板

> 用于快速生成多平台内容矩阵

## 模板说明

本模板用于将核心内容一次改写为多个平台版本。

## 输入信息

```

核心内容：[内容摘要]
目标平台：[平台列表]
发布计划：[发布时间]
```
