# 去AI味规则系统

> 让内容更像真人创作，避免AI痕迹

## 核心原则

AI生成内容有明显的「机器味」，主要表现为：

- 套路化开头结尾
- 过度使用连接词
- 结构过于完美
- 缺乏真实情感
- 语言过于正式

## 禁用表达

### 必须避免的AI腔

| 禁用表达 | 替代方案 |
|----------|----------|
| 首先...其次...最后 | 直接开始叙述 |
| 综上所述 | 所以说 / 总的来说 |
| 值得注意的是 | 说实话 / 坦白讲 |
| 毋庸置疑 | 没错，确实 |
| 从某种意义上说 | 说白了 |
| 众所周知 | 其实 |
| 不可否认 | 话虽如此 |
| 事实上 | 实际上 |
| 总的来说 | 整体看 |
| 就我而言 | 我觉得 / 我认为 |
| 让我们来探讨 | 直接开始 |
| 换句话说 | 也就是说 |
| 除此之外 | 而且 |
| 一方面...另一方面 | 直接对比 |
| 在此基础上 | 接着 |
| 值得关注的是 | 重点是 |
| 可以看出 | 看得出来 |
| 通过以上分析 | 分析下来 |
| 本文旨在 | 这篇文章 |

### 过度使用连接词

| 禁用 | 替代 |
|------|------|
| 因此 | 所以 |
| 然而 | 但是 |
| 并且 | 而且 |
| 同时 | 一起 |
| 于是 | 然后 |
| 虽然 | 虽说 |
| 既然 | 既然这样 |

## 增强真实感

### 中文自然表达

- 使用口语化表达
- 允许适当重复（强调）
- 使用行业黑话/术语
- 适当使用方言词汇

### 情绪感增强

- 加入个人经历
- 描述真实场景
- 表达真实感受
- 允许情绪波动

### 真人经验感

- 第一人称叙述
- 具体案例分享
- 细节描写
- 主观判断

### 社交平台语感

| 平台 | 语感要求 |
|------|----------|
| 微信 | 行业深度，朋友圈风格 |
| 小红书 | 生活化，有温度，真实分享 |
| 知乎 | 专业但可读，理性分析 |
| 抖音 | 口播感，短视频节奏 |

## 各平台去AI味指南

### 微信平台

**保留：**
- 行业深度分析
- 专业见解
- 真实案例

**改进：**
- 减少套话
- 增加个人视角
- 增加情感色彩
- 允许口语化

**示例：**
```
❌ AI腔：首先，我们需要明确...
✅ 自然表达：说到这个，我之前遇到过...

❌ AI腔：综上所述，我们可以得出...
✅ 自然表达：所以说白了，就是这么回事...
```

### 小红书平台

**保留：**
- 真实经历
- 实用干货
- 个人感受

**改进：**
- 增加emoji
- 口语化表达
- 增加情绪词
- 制造共鸣感

**示例：**
```
❌ AI腔：本文将从以下几个方面进行介绍...
✅ 自然表达：姐妹们！这个真的超有用！

❌ AI腔：需要注意以下几点...
✅ 自然表达：划重点！这些坑千万别踩！
```

### 知乎平台

**保留：**
- 专业分析
- 数据支撑
- 逻辑清晰

**改进：**
- 减少模板感
- 增加独特视角
- 允许主观观点
- 减少完美主义

**示例：**
```
❌ AI腔：作为一名专业人士，我认为...
✅ 自然表达：做了这么多年，我的感觉是...

❌ AI腔：基于上述分析，我们可以得出结论...
✅ 自然表达：说白了，就是这么回事...
```

### 抖音平台

**保留：**
- 核心信息
- 实用价值

**改进：**
- 口语化
- 快节奏
- 情绪感染
- 互动引导

**示例：**
```
❌ AI腔：首先...其次...最后...
✅ 自然表达：先说第一个，然后是这个，最后最重要的...

❌ AI腔：综上所述...
✅ 自然表达：好了，说了这么多，总结一下就是...
```

## 快速改写技巧

### 模板改写

将AI模板：
```
首先，[内容]
其次，[内容]
最后，[内容]
```

改为自然表达：
```
说到这个，得先搞清楚一件事——[内容]

然后呢，[内容]

最后，也是最关键的，[内容]
```

### 长句拆分

将AI长句：
```
因此，在这种情况下，我们需要采取相应的措施来应对可能出现的各种问题。
```

改为自然短句：
```
所以啊，得想个办法应对这些问题。
```

### 专业词替换

将过于正式的表达：
```
进行深入分析
```

改为更自然的表达：
```
好好琢磨了一下
```
