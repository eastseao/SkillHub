# 内链优化系统

> 建立强大的站内内容互联网络

## 核心原则

内链是SEO的血管，负责传递权重和引导用户。

## 内链策略

### 1. 内链结构设计

```
网站首页
    │
    ├── 主题簇首页（Pillar）
    │       │
    │       ├── Cluster页面1
    │       │       └── 详细内容页
    │       │
    │       ├── Cluster页面2
    │       │       └── 详细内容页
    │       │
    │       └── Cluster页面3
    │               └── 详细内容页
    │
    └── 专题/落地页
            │
            ├── 案例页
            ├── 对比页
            ├── 知识库页
            └── 转化页
```

### 2. 内链密度控制

| 页面类型 | 内链数量 | 建议锚文本 |
|----------|----------|------------|
| 首页 | 30-50个 | 品牌词+核心词 |
| Pillar页 | 15-25个 | 核心长尾词 |
| Cluster页 | 10-15个 | 相关长尾词 |
| 内容页 | 5-10个 | 相关内容词 |

### 3. 锚文本规则

**正确示范：**
- 自然的句子中嵌入链接
- 锚文本多样化
- 指向相关页面

**错误示范：**
- 堆砌关键词
- 相同的锚文本链接到不同页面
- 使用「点击这里」等无意义锚文本

### 4. 内链位置策略

```
文章开头：
- 1-2个内链（指向相关基础概念页）

文章中段：
- 每个H2章节1-2个内链
- 自然融入，不要刻意

文章结尾：
- 2-3个内链
- 指向相关文章/CTA页
- 推荐阅读模块
```

## 内链建设流程

### STEP 1: 内容盘点

盘点现有内容，识别：
- 核心主题
- 子主题
- 页面关系
- 链接机会

### STEP 2: 链接规划

为每个主题簇规划：
- 支柱页面（Pillar）
- 簇页面（Cluster）
- 详细内容页
- 链接关系图

### STEP 3: 锚文本设计

设计自然的锚文本：
- 核心词锚文本
- 长尾词锚文本
- 品牌词锚文本
- 自然句锚文本

### STEP 4: 实施与监控

实施链接并监控：
- 爬虫抓取
- 权重传递
- 用户行为

```
| 源页面 | 目标页面 | 锚文本 | 位置 | 优先级 |
|--------|----------|--------|------|--------|
|        |          |        |      |        |
```

### 链接建议模板

```
在[current_page]这篇文章中，建议添加以下内链：

1. 位于[位置]：
   - 锚文本：「[关键词]」
   - 链接到：「[目标页面]」
   - 理由：[原因说明]

2. 位于[位置]：
   - 锚文本：「[关键词]」
   - 链接到：「[目标页面]」
   - 理由：[原因说明]

...
```

### 推荐阅读模块

```
建议在文章底部添加推荐阅读模块：

相关文章：
- [文章1] - [简短描述]
- [文章2] - [简短描述]
- [文章3] - [简短描述]

相关专题：
- [专题名] - [简短描述]
```
