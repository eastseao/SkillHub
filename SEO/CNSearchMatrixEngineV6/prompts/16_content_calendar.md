# 内容日历系统

> 科学规划内容发布计划

## 核心概念

好的内容日历可以实现：
- 稳定的内容输出
- 平台覆盖最大化
- 用户期待管理
- 资源合理分配

## 内容规划原则

### 1. 内容类型配比

| 类型 | 占比 | 作用 |
|------|------|------|
| 引流内容 | 30% | 吸引流量，扩大覆盖 |
| 转化内容 | 20% | 促进转化，带来收益 |
| 品牌内容 | 20% | 建立品牌，传递价值 |
| 互动内容 | 15% | 增强互动，提升粘性 |
| 热点内容 | 15% | 借势热点，获取流量 |

### 2. 发布频率建议

| 平台 | 最低频率 | 建议频率 | 最佳时间 |
|------|----------|----------|-----------|
| 官网/Blog | 2篇/周 | 3-4篇/周 | 周二-周四 |
| 微信公众号 | 1篇/周 | 2-3篇/周 | 周二-周五 |
| 小红书 | 3篇/周 | 5-7篇/周 | 每天 |
| 知乎 | 2篇/周 | 3-5篇/周 | 周一-周五 |
| 抖音 | 3条/周 | 5-7条/周 | 每天 |
| 百家号 | 1篇/天 | 1-2篇/天 | 每天 |

### 3. 发布节奏设计

**周节奏示例：**
```
周一：重磅内容发布（引流）
周二：常规内容 + 互动话题
周三：转化内容 + 案例分享
周四：常规内容 + FAQ
周五：轻量内容 + 周末预告
周六：热点借势 + 互动
周日：用户投稿 + 回顾总结
```

## 内容规划流程

### STEP 1: 月度规划

```
每月25日进行下月规划：
1. 确定月度主题
2. 规划重要节点内容
3. 分配资源
4. 确定发布节奏
```

### STEP 2: 周度细化

```
每周一进行本周规划：
1. 确定周主题
2. 细化每天内容
3. 准备素材
4. 确认发布时间
```

### STEP 3: 执行追踪

```
每日：
1. 发布内容
2. 监测数据
3. 记录表现

每周：
1. 周数据复盘
2. 下周计划调整
```

### STEP 4: 月度复盘

```
每月最后一天：
1. 汇总月度数据
2. 分析内容表现
3. 优化下月策略
```

```
│   ├── 开场白库/

│   └── 金句库/

    ├── 行业数据/
    └── 案例数据/
```

### 库存预警

```
绿色：库存充足（>30天用量）
黄色：库存不足（7-30天用量）
红色：库存紧张（<7天用量）
```

## 跨平台协同

### 一鱼多吃策略

```
一篇核心内容 → 多平台改写

原创长文（官网）
    │
    ├── 精简版（公众号）
    ├── 精华摘录（小红书）
    ├── 专业分析（知乎）
    ├── 口播脚本（抖音）
    └── FAQ改写（百家号）
```

### 内容优先级

```
P0：核心主题簇内容（月度重点）
P1：重要节点内容（节日/事件）
P2：常规更新内容（稳定输出）
P3：热点借势内容（灵活把握）
```
