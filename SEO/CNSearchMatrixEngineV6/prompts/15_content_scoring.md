# 内容评分模型

> 科学的评估内容价值体系

## 评分模型概述

内容评分 = SEO价值 + AI引用概率 + 商业价值 + 平台传播性 + 转化能力

每项20分，总分100分。

## 评分维度详解

### 1. SEO价值（20分）

| 评分 | 标准 |
|------|------|
| 18-20 | 关键词覆盖完整，密度适中，结构优秀 |
| 14-17 | 关键词布局合理，结构良好 |
| 10-13 | 基础SEO优化，有提升空间 |
| 5-9 | SEO优化不足 |
| 0-4 | 无SEO优化 |

**评估要素：**
- 标题包含关键词
- H标签结构正确
- 关键词密度（2-3%）
- 长尾关键词覆盖
- 图片ALT标签
- 内链布局

### 2. AI引用概率（20分）

| 评分 | 标准 |
|------|------|
| 18-20 | 定义清晰，有TL;DR，结构化，数据支撑 |
| 14-17 | 有AI友好的结构，引用优化到位 |
| 10-13 | 基础AI优化，有提升空间 |
| 5-9 | AI优化不足 |
| 0-4 | 无AI优化 |

**评估要素：**
- TL;DR摘要
- 实体定义
- FAQ结构
- 数据支撑
- 结构化程度
- 来源标注

### 3. 商业价值（20分）

| 评分 | 标准 |
|------|------|
| 18-20 | 高商业价值，直接促进转化 |
| 14-17 | 较高商业价值 |
| 10-13 | 中等商业价值 |
| 5-9 | 商业价值有限 |
| 0-4 | 无商业价值 |

**评估要素：**
- 目标用户精准度
- 需求匹配度
- 购买意愿触发
- 信任建立能力
- 差异化价值
- 定价相关信息

### 4. 平台传播性（20分）

| 评分 | 标准 |
|------|------|
| 18-20 | 非常适合传播，病毒潜力高 |
| 14-17 | 传播性好 |
| 10-13 | 有一定传播性 |
| 5-9 | 传播性一般 |
| 0-4 | 无传播性 |

**评估要素：**
- 情感共鸣度
- 实用价值
- 分享便捷度
- 视觉吸引力
- 时效性
- 话题性

### 5. 转化能力（20分）

| 评分 | 标准 |
|------|------|
| 18-20 | 转化路径清晰，CTA优秀 |
| 14-17 | 转化设计合理 |
| 10-13 | 有基本转化设计 |
| 5-9 | 转化设计不足 |
| 0-4 | 无转化设计 |

**评估要素：**
- CTA位置和文案
- 转化路径清晰度
- 信任背书
- 紧迫感设计
- 用户行动成本
- 后续跟进机制

## 评分使用指南

### 80分以上内容

- 优先发布
- 多平台分发
- 重点更新维护
- 投入资源推广

### 70-79分内容

- 常规发布
- 适当推广
- 持续优化

### 60-69分内容

- 需要优化后发布
- 优化优先级：转化/SEO

### 60分以下内容

- 建议重构
- 暂缓发布
- 分析原因
