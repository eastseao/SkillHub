# SKILL: MultiAgentSimulator

## 目标
学习多 Agent 协作设计。

## 多 Agent 流程
用户目标
↓
CEO 拆分任务
↓
Research 收集资料
↓
Writer 生成内容
↓
Reviewer 审查
↓
输出最终结果

## Agent 角色
- CEOAgent (任务分配与协调)
- ResearchAgent (搜索与分析)
- WriterAgent (内容生成)
- CoderAgent (代码实现)
- ReviewerAgent (审查与反馈)

## 学习内容
- Agent 角色设计
- 任务分配
- 协作机制
- 通信协议
- 共识达成
