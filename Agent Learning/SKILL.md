# Agent Learning Skill Suite V1

## 概述

一套用于「系统性学习 AI Agent」的 OpenClaw/QClaw 风格 Skill 体系。

## 目标

- 边学边做
- 通过 Skill 工程化学习 Agent
- 建立自己的 Agent 学习系统
- 从 Prompt 工程进阶到 Agent Engineering

## 学习路线

### 第一阶段（7天）
**重点**: Prompt / Tool / Workflow / Memory
**目标**: 做出单 Agent

### 第二阶段（30天）
**重点**: LangGraph / Dify / Coze / MCP / RAG
**目标**: 做出企业级 Workflow Agent

### 第三阶段（60天）
**重点**: Multi-Agent / Autonomous Agent / Reflection / Planning
**目标**: 做出自动化 AI 员工

### 第四阶段（长期）
**重点**: Agent Runtime / Persistent Memory / Browser Agent / 沙盒执行 / 多模态 Agent / Agent 网络
**目标**: 构建完整 AI Agent 平台
