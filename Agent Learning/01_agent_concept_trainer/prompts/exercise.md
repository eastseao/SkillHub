## 练习

选择一个你感兴趣的方向，完成以下任务：

### 练习 1：ReAct Agent
请设计一个基于 ReAct 模式的 Agent，需要包含：
- Thought
- Action
- Observation
- 循环终止条件

### 练习 2：Memory 系统
请为一个客服 Agent 设计记忆系统：
- 短期记忆：会话上下文
- 长期记忆：用户画像
- 工作流状态

### 练习 3：Tool Calling
请为 Agent 添加以下工具：
- 搜索工具
- 文件读写工具
- API 调用工具
- 错误处理机制

完成后，请提交你的设计文档。
