# Decision Making

## Decision Types

### Programmed Decisions
- Routine, repetitive
- Clear policies and procedures
- High frequency
- Low stakes per decision

### Non-Programmed Decisions
- Novel, unstructured
- No clear precedent
- Low frequency
- High stakes

## Decision-Making Models

### Rational Model
1. Define the problem
2. Identify criteria
3. Weight criteria
4. Generate alternatives
5. Evaluate alternatives
6. Select best option
7. Implement
8. Evaluate

### Bounded Rationality (Simon)
- Information is incomplete
- Cognitive limits exist
- Satisficing vs maximizing
- Use heuristics when appropriate

### Intuitive Model (Klein - Recognition-Primed)
1. Situation recognition through pattern matching
2. Expectation confirmation
3. Mental simulation
4. Make decision

## Decision Quality Criteria

| Criterion | Question |
|-----------|----------|
| Truth | Is it based on accurate information? |
| Relevance | Does it address the real problem? |
| Perspective | Have alternatives been fairly considered? |
| Support | Can reasoning be explained and defended? |
| Outcome | Did it achieve intended results? |

## Common Biases to Avoid
- Confirmation bias
- Anchoring
- Sunk cost fallacy
- Availability heuristic
- Overconfidence
- Groupthink
