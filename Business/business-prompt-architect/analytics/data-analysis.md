# Data Analysis

## Analysis Types

### Descriptive Analytics
What happened?
- Summary statistics
- Trend analysis
- Comparative analysis
- Distribution analysis

### Diagnostic Analytics
Why did it happen?
- Root cause analysis
- Correlation analysis
- Variance analysis
- Factor analysis

### Predictive Analytics
What will happen?
- Forecasting models
- Classification models
- Clustering analysis
- Propensity modeling

### Prescriptive Analytics
What should we do?
- Optimization models
- Scenario planning
- Simulation
- Recommendation engines

## Analysis Process

Define Question -> Collect Data -> Clean Data -> Analyze -> Visualize -> Interpret -> Communicate

## Key Statistical Concepts

### Measures of Central Tendency
- Mean: Average value
- Median: Middle value
- Mode: Most frequent value

### Measures of Variability
- Standard deviation
- Variance
- Range
- Interquartile range

### Correlation vs Causation
- Correlation: Statistical relationship
- Causation: Direct influence
- Confounding variables
- Spurious correlations
