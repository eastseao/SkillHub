# Forecasting

## Forecasting Methods

### Qualitative Methods
- Expert judgment
- Delphi method
- Sales force composite
- Customer intention surveys

### Quantitative Methods

#### Time Series
- Moving average
- Exponential smoothing
- ARIMA models
- Seasonal decomposition

#### Causal Models
- Linear regression
- Multiple regression
- Econometric models
- Leading indicators

## Forecasting Process

1. Define purpose and scope
2. Select time horizon
3. Gather and clean data
4. Choose methodology
5. Build and validate model
6. Generate forecast
7. Communicate uncertainty
8. Monitor and adjust

## Forecast Accuracy

### Common Metrics
- Mean Absolute Error (MAE)
- Mean Absolute Percentage Error (MAPE)
- Root Mean Square Error (RMSE)
- Bias

### Improving Accuracy
- Use multiple methods
- Ensemble forecasts
- Document assumptions
- Track actuals vs forecast
- Regular recalibration
