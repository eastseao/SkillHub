# Dashboard Design

## Dashboard Types

### Strategic Dashboard
- High-level KPIs
- Trend over time
- Executive summary
- Low granularity

### Operational Dashboard
- Real-time metrics
- Process metrics
- Alerts and exceptions
- High granularity

### Analytical Dashboard
- Deep dive capability
- Multiple dimensions
- Customizable views
- Ad-hoc analysis

## Design Principles

### Information Hierarchy
1. Most important metric
2. Supporting context
3. Detailed breakdown
4. Raw data (optional)

### Visual Design
Choose appropriate chart types:
- Time series: Line chart
- Part-to-whole: Pie/donut
- Comparison: Bar chart
- Distribution: Histogram
- Correlation: Scatter plot
- Funnel: Funnel chart

### Color Usage
- Use color purposefully
- Maintain accessibility (color blindness)
- Limit to 5-7 colors
- Use red/green consistently for negative/positive

## Dashboard QA Checklist
- [ ] Data source is reliable
- [ ] Metrics are correctly calculated
- [ ] Date range is appropriate
- [ ] Comparisons are like-for-like
- [ ] Outliers are explained
- [ ] Charts are labeled clearly
- [ ] Key insight is visible
