# Report Generation

## Report Types

### Executive Summary Report
- 1-2 pages maximum
- Key findings upfront
- Minimal methodology
- Actionable recommendations

### Comprehensive Report
- Full methodology
- Detailed findings
- Supporting data
- Strategic recommendations

### Analytical Brief
- Focused on specific question
- Concise analysis
- Key insights
- Supporting evidence

## Report Structure Template

# [Report Title]

## Executive Summary
[3-5 key points covering main findings and recommendations]

## Introduction
- Background
- Objectives
- Scope
- Methodology

## Key Findings
### Finding 1: [Title]
[Supporting evidence, data, analysis]

### Finding 2: [Title]
...

## Analysis
[Detailed analysis, interpretations, relationships between findings]

## Recommendations
[Numbered, actionable suggestions with rationale]

## Limitations
[Acknowledgment of scope and methodology constraints]

## Appendix
[Supporting data, methodology details, references]

## Data Visualization Recommendations
- Choose chart types based on data type
- Minimize chartjunk
- Use color purposefully
- Label clearly
- Source all data

## Quality Checklist
- [ ] Executive summary stands alone
- [ ] All claims backed by evidence
- [ ] Methodology is transparent
- [ ] Limitations acknowledged
- [ ] Recommendations are specific and actionable
- [ ] Formatting is consistent
- [ ] Key metrics are highlighted
